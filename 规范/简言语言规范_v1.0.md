## 0. 语言定位

| 项目 | 定位 |
|---|---|
| 目标 | 让读不懂 C 的人能读懂；性能接近 C，不学 Python 的慢 |
| 风格 | 中文关键字、半角符号、C 式骨架、无分号 |
| 内存 | 所有权 + 借用，编译期自动释放，无 GC |
| 错误 | `可空` + `结果`，无异常 |
| 并发 | 线程 + 通道 + 异步，跨线程禁借用 |
| 实现 | 解释器 → 字节码 VM → LLVM |

## 1. 词法

### 1.1 字符集与符号

- 源文件 UTF-8。
- 符号一律半角：`() {} [] , : . + - * / % ^ = == != << >> <= >= ~ .. -> & | ! ? @ #`
- 禁止全角括号、逗号、引号、运算符。

### 1.2 注释

```
-- 单行注释
--[[
多行注释
]]
```

### 1.3 标识符

- 中文、英文、数字、下划线，不能以数字开头，区分大小写。
- 类型参数惯例用大写单字母：`T` `U` `K` `V`。

### 1.4 关键字（完整）

| 类别 | 关键字 |
|---|---|
| 类型 | `整数` `整数8` `整数16` `整数32` `整数64` `浮点` `布尔值` `字符串` `空值` `组` `映射` `可空` `结果` `元组` `函数` `任意` `类型` `通道` |
| 修饰 | `不可变` `常量` `私有` |
| 推导 | `令` |
| 函数 | `函数` `返回` `异步` |
| 结构 | `结构` `枚举` `接口` `实现` `为` `继承` `自身` `新建` |
| 条件 | `如果` `就` `否则如果` `否则` |
| 循环 | `当` `重复循环直到` `对` `在` `步长` `循环` `打断` `继续` |
| 并发 | `线程` `通道` `发送` `接收` `关闭` `等待` |
| 匹配 | `匹配` `例` `默认` |
| 逻辑 | `与` `或` `非` |
| 位运算 | 全部使用符号（`&` `\|` `^^` `~~` `<<<` `>>>`），不设中文别名 |
| 模块 | `模块` `引入` `导出` |
| 内存 | `借用` `可变借用` `复制` `移动` |
| 错误 | `成功` `失败` `失败返回` |
| 并发 | `线程` `通道` `发送` `接收` `关闭` `等待` |
| 元编程 | `编译期` `宏` |
| 测试 | `测试` `断言` `断言相等` `断言失败` `断言成功` |
| 外部 | `外部` `不安全` |
| 字面量 | `真` `假` `空` |

> 注：`位非` 只作可读别名保留，规范写法统一用 `~~`。

### 1.5 字面量

| 类型 | 字面量 |
|---|---|
| 整数 | `1` `-5` `0x1F` `0b1010` `1_000` |
| 浮点 | `1.0` `3.14` `1e9` |
| 布尔值 | `真` `假` |
| 字符串 | `"..."` `[[...]]` |
| 空 | `空` |
| 数组 | `{1, 2, 3}` |
| 映射 | `{"键": 值}` |
| 元组 | `(1, "a")` |

转义：`\n \t \\ \" \0`。

### 1.6 运算符与优先级

| 级 | 运算符 | 结合 | 说明 |
|---|---|---|---|
| 1 | `()` `[]` `.` `->` | 左 | 后缀 |
| 2 | `^` | 右 | 乘方 |
| 3 | `非` `!` `#` `~~` `-`(一元) `+`(一元) | 右 | 一元 |
| 4 | `*` `/` `//` `%` | 左 | 乘、除、整除、取余 |
| 5 | `+` `-` | 左 | 加减 |
| 6 | `<<<` `>>>` | 左 | 移位 |
| 7 | `<<` `>>` `<=` `>=` | 左 | 大小比较 |
| 8 | `==` `!=` | 左 | 相等 |
| 9 | `&` | 左 | 按位与 |

| 15 | `=` | 右 | 赋值（无复合赋值） |

词法注意：`^^` `~~` `<<<` `>>>` 按最长匹配整体识别。

## 2. 类型系统

### 2.1 基本类型

| 类型 | 宽度 | 范围 / 说明 |
|---|---|---|
| `整数` | 64 位有符号 | 默认整数类型，等价 `整数64` |
| `整数8` | 8 位有符号 | −128 ~ 127 |
| `整数16` | 16 位有符号 | −32768 ~ 32767 |
| `整数32` | 32 位有符号 | 与 C `int32_t` 对齐 |
| `整数64` | 64 位有符号 | |
| `浮点` | 64 位 IEEE754 | 等价 C `double` |
| `布尔值` | 1 位逻辑 | `真` / `假` |
| `字符串` | UTF-8 序列 | 不可变，长度按字符计 |
| `图` | RGBA8 像素缓冲 + 宽高 | **句柄**，赋值共享同一张图。v0.7 新增，见 §16.4 |
| `空值` | 无值 | 仅 `空` |

**整数溢出**：默认**硬件回绕**（与 Rust release 一致），可用 `std.math.溢出加` 等显式检查。编译器在能静态发现溢出时给出警告。

**字符串下标**：`s[i]` 返回单字符字符串，越界 panic；安全写法用 `std.string.取(s, i) -> 可空[字符串]`。

**`图` 为什么是句柄**：一张 1200×750 的图是 3.6 MB。如果 `私有 图 乙 = 甲` 悄悄拷一份，
写起来轻松、跑起来灾难。所以赋值和传参都只搬那个 24 字节的句柄，
需要独立副本时显式写 `甲.缩放(宽, 高)`（本来就要分配新内存）。
这和 `字符串` 的做法一致，区别只在于图是可变的、字符串不是。

### 2.2 复合类型

| 写法 | 含义 |
|---|---|
| `整数 组` | 动态数组 |
| `整数 组[10]` | 定长数组 |
| `映射[字符串, 整数]` | 键值映射 |
| `元组[整数, 字符串]` | 元组 |
| `可空[整数]` | 可能为 `空` |
| `结果[整数, 字符串]` | 成功值或错误原因 |
| `函数(整数) -> 整数` | 函数类型 |
| `名[T]` | 泛型实例 |

### 2.3 类型推导

```
令 x = 1              -- int64
令 名 = "张三"        -- 字符串
不可变 令 比例 = 0.5  -- 浮点
```

- 只用于变量声明，函数参数与返回值必须显式标注。
- 空集合必须靠目标类型确定元素类型：`整数 组 空表 = {}`。

### 2.4 类型转换

```
浮点 y = 浮点(3)        -- 整数转浮点，安全
整数 n = 整数(3.9)      -- 截断取整，向零
整数32 m = 整数32(n)    -- 窄化，可能截断
```

- 禁止隐式转换；混合类型运算必须显式转换。
- 字符串转数字用 `std.string.转整数/转浮点`，返回 `结果`。

## 3. 变量与作用域

```
-- 顶层：全局，默认公开
整数 全局计数 = 0
常量 整数 最大值 = 100

函数 main() -> 整数 {
    私有 整数 局部 = 1        -- 函数内必须 私有
    不可变 字符串 标题 = "只读"
    私有 令 推导 = 42
    返回 局部
}
```

| 规则 | 说明 |
|---|---|
| 默认可变 | 不加修饰即可赋值 |
| 不可变 | 只读，编译器可做常量传播 |
| 常量 | 编译期求值，必须能在编译期算完 |
| 私有 | 函数内局部变量必须写；顶层写则仅本模块可见 |
| 参数 | 禁止 `私有` |
| 块作用域 | `{}` 内声明仅在块内有效 |
| 遮蔽 | 内层可同名遮蔽外层，编译器警告 |

## 4. 表达式

### 4.1 运算符语义

| 类别 | 规则 |
|---|---|
| `+ - *` | 整数或浮点，两边同类型 |
| `/` | **总是返回浮点**；整数相除也得浮点 |
| `//` | 仅整数，向零取整 |
| `%` | 整数或浮点，结果符号随被除数 |
| `^` | 乘方，右结合，`-2^2 = -4` |
| `<<` `>>` | 小于 / 大于（不是移位） |
| `<<<` `>>>` | 左移 / 右移，仅整数，位数非负 |
| `&` `\|` `^^` | 按位与 / 或 / 异或，仅整数 |
| `~~` | 按位取反，仅整数 |
| `与` `或` `非` | 逻辑，仅布尔，短路求值 |
| `..` | 字符串拼接，两边必须都是字符串 |
| `#` | 长度，作用于数组、字符串、映射 |
| `==` `!=` | 相等比较，同类型 |

数字与字符串**不能**直接拼接：`"共 " .. 字符串(3) .. " 人"`。

### 4.2 匿名函数

```
私有 函数(整数) -> 整数 加倍 = 函数(x: 整数) -> 整数 {
    返回 x * 2
}

-- 参数类型可省略（由目标类型推导）
私有 数组[整数] 偶数 = 数字.过滤(函数(x) -> 布尔值 = x % 2 == 0)
```

- 统一用 `函数(...)`，不引入 `|x|` 或 `=>`（`|` 已是按位或）。
- 捕获默认借用；需长期持有外部值时写 `移动 函数(...)`。

### 4.3 构造

```
结构 点 { x: 浮点, y: 浮点 }

私有 点 甲 = { 1.0, 2.0 }        -- 省略类型名和字段名
私有 点 乙 = 点{ 1.0, 2.0 }      -- 显式类型名，仍省略字段名
私有 点 丙 = 点{ x: 1.0, y: 2.0 }-- 字段名可读性更好时写全
```

- 默认按位置构造；字段多或易混时写字段名。
- 枚举：`形状.圆(1.0)`，无歧义时可省类型名 `圆(1.0)`。

## 5. 语句与控制流

### 5.1 条件

```
如果 成绩 >= 90.0 就 {
    打印("优秀")
} 否则如果 成绩 >= 60.0 就 {
    打印("及格")
} 否则 {
    打印("不及格")
}
```

- 条件必须是 `布尔值`，禁止隐式真值。
- 块必须 `{}`，单行也不省。

### 5.2 循环（三种）

```
-- 先判断
当 i << 10 就 {
    i = i + 1
}

-- 先执行，后判断
重复循环直到 i >= 10 {
    i = i + 1
}

-- 范围：含结束值
对 n: 1~5 {
    打印(字符串(n))
}

对 n: 0~10, 步长: 2 {
    打印(字符串(n))
}

-- 遍历集合
对 项 在 数组 {
    ...
}

对 索引, 项 在 数组 {
    ...
}

对 键, 值 在 映射 {
    ...
}
```

| 规则 | 说明 |
|---|---|
| `~` 范围 | 含结束值 |
| 步长 | 仅范围可用，默认 1，可为负 |
| 循环变量 | 天然局部、不可变、不写 `私有` |
| 数组/映射遍历 | 不写步长 |
| 映射顺序 | 不保证 |

### 5.3 匹配

```
匹配 命令 {
    例 "start": { 启动() }
    例 "stop": { 停止() }
    例 0~9: { 打印("单个数字") }
    例 形状.圆(半径): { 打印(字符串(半径)) }
    默认: { 打印("未知") }
}
```

- 必须穷尽，编译器检查。
- 支持字面量、范围、枚举解构、`_` 通配。

### 5.4 跳转

```
对 i: 1~100 {
    如果 i % 2 == 0 就 { 继续 }
    如果 i >> 50 就 { 打断 }
}
```

## 6. 函数

```
函数 加法(甲: 整数, 乙: 整数) -> 整数 {
    返回 甲 + 乙
}

-- 表达式体
函数 平方(x: 整数) -> 整数 = x * x

-- 无返回值
函数 打印(x: 整数) {
    std.io.打印行(字符串(x))
}

-- 泛型
函数 最大[T: 可比较](甲: T, 乙: T) -> T {
    如果 甲 >> 乙 就 { 返回 甲 }
    返回 乙
}

-- 异步
异步 函数 读取(路径: 字符串) -> 结果[字符串, 字符串] {
    ...
}
```

| 规则 | 说明 |
|---|---|
| 参数类型 | 必须显式 |
| 返回值 | `-> 类型`，无则省略 |
| 嵌套函数 | 不支持，用匿名函数 |
| 重载 | 不支持，用泛型或不同名 |
| 递归 | 支持 |

## 7. 结构、枚举、接口

### 7.1 结构

```
结构 学生 {
    名字: 字符串
    年龄: 整数
    成绩: 浮点
}
```

### 7.2 枚举

```
枚举 形状 {
    圆(半径: 浮点)
    矩(宽: 浮点, 高: 浮点)
    点
}
```

- 变体可带字段，也可无字段。
- 递归枚举通过容器间接（数组、映射在堆上），大小固定。

### 7.3 接口

```
接口 可打印 {
    函数 打印() -> 字符串

    函数 打印行() {              -- 默认方法
        std.io.打印行(打印())
    }
}

接口 可比较 {
    函数 比较(其他: 借用 自身) -> 整数
}

接口 可排序 继承 可比较 {
    函数 排序()
}
```

- 默认方法可被实现者覆盖。
- `自身` 指实现类型。
- 接口不能有字段，状态用 getter。
- 接口可有常量。

### 7.4 实现

```
实现 学生 为 可打印, 可排序 {
    函数 打印() -> 字符串 {
        返回 名字 .. "（" .. 字符串(年龄) .. "岁）"
    }
    函数 比较(其他: 借用 学生) -> 整数 {
        返回 年龄 - 其他.年龄
    }
    函数 排序() {
        ...
    }
}
```

## 8. 泛型

```
-- 函数
函数 收集[T](项: 借用 数组[T]) -> 数组[T] {
    私有 数组[T] 结果表 = {}
    对 x 在 项 {
        结果表.追加(复制 x)
    }
    返回 结果表
}

-- 结构
结构 栈[T] {
    数据: 数组[T]
}

-- 接口与实现
接口 容器[T] {
    函数 添加(项: T)
    函数 大小() -> 整数
}

实现 栈[T] 为 容器[T] {
    函数 添加(项: T) {
        数据.追加(项)
    }
    函数 大小() -> 整数 {
        返回 #数据
    }
}
```

| 规则 | 说明 |
|---|---|
| 约束 | `[T: 接口]`，多约束 `[T: 可比较 与 可打印]` |
| 实现方式 | 单态化，编译期展开，零运行时开销 |
| 不做 | 特化、关联类型、高阶类型、变型标注 |
| 动态分发 | v1.0 不提供 |

## 9. 内存模型

| 概念 | 规则 |
|---|---|
| 所有权 | 每个值唯一所有者，离开作用域自动释放 |
| 移动 | 赋值、传参默认移动（结构、数组、字符串、映射） |
| 复制 | 简单类型（整数、浮点、布尔）默认复制；其他需 `复制 值` |
| 借用 | `借用 值` 只读；`可变借用 值` 可写 |
| 借用规则 | 多读或一写，不能同时；借用不长于所有者 |
| 生命周期 | 编译器推断，不手写 |
| GC | 无 |
| 释放 | 编译期插入，零运行时开销 |

```
函数 查看(s: 借用 学生) { 打印(s.名字) }
函数 改名(s: 可变借用 学生) { s.名字 = "李四" }

私有 学生 甲 = { "张三", 18 }
查看(借用 甲)
改名(可变借用 甲)
私有 学生 乙 = 复制 甲
```

## 10. 错误处理

### 10.1 两种容器

| 容器 | 用途 | 构造 | 判断 |
|---|---|---|---|
| `可空[T]` | 可能没有值（无原因） | `空` / 值 | `== 空`、`.取值()`、`.或默认(x)` |
| `结果[T, E]` | 成功有值，失败有原因 | `成功(v)` / `失败(e)` | `匹配`、`失败返回` |

### 10.2 传播

```
函数 取名字(学号: 整数) -> 结果[字符串, 字符串] {
    私有 学生 甲 = 查找(学号) 失败返回
    返回 成功(甲.名字)
}
```

- `表达式 失败返回`：失败则立即 `返回 失败(原因)`，成功则取值继续。
- 仅用于 `结果`；当前函数必须也返回 `结果`，且错误类型兼容。

### 10.3 不设计异常

- 没有 `抛出` / `捕获`，没有栈展开开销。
- 不可恢复错误（数组越界、除零）直接终止并打印调用栈与位置。

### 10.4 组合示例

```
函数 读配置(路径: 字符串) -> 结果[整数, 字符串] {
    私有 字符串 文本 = std.fs.读取文件(路径) 失败返回
    私有 整数 端口 = std.string.转整数(文本) 失败返回
    如果 端口 << 1 或 端口 >> 65535 就 {
        返回 失败("端口越界：" .. 字符串(端口))
    }
    返回 成功(端口)
}
```

## 11. 并发

### 11.1 模型

线程 + 通道 + 异步/等待。不共享内存，靠消息传递。

### 11.2 关键字

| 关键字 | 用途 |
|---|---|
| `线程 { }` | 启动线程 |
| `通道[T]()` / `通道[T](n)` | 创建同步 / 缓冲通道 |
| `发送 通道, 值` | 发送（移动所有权进通道） |
| `接收 通道` | 接收，返回 `可空[T]`，`空` 表示已关闭 |
| `关闭 通道` | 关闭 |
| `异步 函数` | 声明异步函数 |
| `等待 表达式` | 等待异步结果，仅 `异步 函数` 或 `main` |

### 11.3 关键规则

| 规则 | 说明 |
|---|---|
| 跨线程借用 | **禁止**，编译错误 |
| 跨线程传值 | 移动或复制 |
| 线程块内 | 不能借用外部变量，只能借用块内局部 |
| 通道句柄 | 共享句柄，赋值/传参**自动复制**（内部引用计数） |
| 通道关闭后接收 | 返回 `空` |
| 缓冲满时发送 | 阻塞 |
| 线程返回值 | 不支持，用通道传 |

### 11.4 示例

```
通道[整数] 管道 = 通道[整数](10)

线程 {
    对 i: 1~5 {
        发送 管道, i
    }
    关闭 管道
}

循环 {
    私有 可空[整数] 值 = 接收 管道
    如果 值 == 空 就 { 打断 }
    打印(字符串(值.取值()))
}
```

### 16.9 已实装的内置（v0.7）

上面 16.1–16.8 是**规划中的标准库**，带模块前缀。真正跑起来的后端还没有
模块系统，所以把最常用的那批做成了**内置**：不带前缀、全局可见，
由 `简编译` 直接展开成运行时调用或 libm 调用。

| 类别 | 名字 | 说明 |
|---|---|---|
| 输出 | `打印` `打印行` `读入` `退出` | 参数是 `任意` |
| 数学 | `开方` `正弦` `余弦` `正切` `反正弦` `反余弦` `反正切` `指数` `对数` `对数10` `幂` `最小` `最大` `向下取整` `向上取整` `绝对值` | 全直通 libm，参数返回都是 `浮点`；角度用弧度 |
| 数学 | `四舍五入` | `(浮点) -> 整数`，跟 `整数(x)` 的截断不同 |
| 图片 | `新建图` `读图` `存图` | 见 16.10 |

对照关系：`开方` ↔ `std.math.平方根`，`对数10` ↔ `std.math.日志10`。名字不同是有意的——
内置这部分是给"不写 import 也能画图"用的，越短越好。

**用户定义可以顶掉内置。** 写了一个自己的 `开方`，模块里所有 `开方` 都指它，
后端会自动让路（不再展开成 `sqrt`）。这条规则是 v0.7 定的：
内置只是"没有用户版本时的默认实现"，不是保留字。

### 16.10 `图`（v0.7）

像素缓冲，RGBA8、行紧凑、左上角原点。值语义是**共享句柄**，见 §2.1。

| 形式 | 签名 | 说明 |
|---|---|---|
| 新建 | `新建图(宽: 整数, 高: 整数) -> 图` | 不透明黑；宽高必须 > 0 |
| 读 | `读图(路径: 字符串) -> 结果[图, 字符串]` | PNG/JPG/BMP/TGA/GIF/PSD/HDR，以及 SVG |
| 存 | `图.存(路径: 字符串) -> 结果[空值, 字符串]` | 按扩展名选 png/jpg/bmp/tga |
| 取 | `图.取(x: 整数, y: 整数) -> 整数` | 打包成 `0xRRGGBBAA`；越界返回 0 |
| 设 | `图.设(x: 整数, y: 整数, 色: 整数)` | 同上；越界静默忽略 |
| 缩放 | `图.缩放(宽: 整数, 高: 整数) -> 图` | 双线性，返回**新图**（唯一会复制像素的操作） |
| 写字 | `图.写字(x: 整数, y: 整数, 字号: 浮点, 文字: 字符串, 色: 整数) -> 整数` | 返回字数；`-1` 表示没找到字体。`y` 是行顶边 |
| 量字 | `图.量字(文字: 字符串, 字号: 浮点) -> 浮点` | 这行字多宽（像素） |
| 宽 / 高 | `图.宽` `图.高` | 只读属性 |

颜色统一用整数 `0xRRGGBBAA`。没有单独的 `颜色` 类型——加一个类型要改三层，
而这个打包格式跟 `图.取` 的返回值天然一致，`混(甲, 乙, t)` 这样的小函数两行就能写。

字体按这个顺序找，第一个能读的用：环境变量 `简言字体` → Noto Sans CJK →
文泉驿 → DejaVu。**没装任何字体时 `写字` 返回 -1，不崩**，只写不出字来。

### 17.1 示例一：词频统计（命令行工具）

覆盖：模块引入、结构、映射、借用、匹配、错误处理、高阶函数、范围循环。

```简言
模块 词频

引入 std.io
引入 std.string
引入 std.array
引入 std.map
引入 std.os
引入 std.fs

结构 词频项 {
    词: 字符串
    次数: 整数
}

函数 统计(文本: 借用 字符串) -> 映射[字符串, 整数] {
    私有 映射[字符串, 整数] 表 = {}
    私有 数组[字符串] 词们 = std.string.分割(文本, " ")

    对 词 在 词们 {
        私有 字符串 干净 = std.string.去空白(std.string.小写(词))
        如果 #干净 == 0 就 { 继续 }

        私有 可空[整数] 旧 = 表.取(干净)
        如果 旧 == 空 就 {
            表.插入(干净, 1)
        } 否则 {
            表.插入(干净, 旧.取值() + 1)
        }
    }
    返回 表
}

函数 排行(表: 借用 映射[字符串, 整数]) -> 数组[词频项] {
    私有 数组[词频项] 项们 = {}
    对 词, 次数 在 表 {
        项们.追加({ 复制 词, 次数 })
    }
    项们.排序按(函数(甲: 词频项, 乙: 词频项) -> 整数 {
        返回 乙.次数 - 甲.次数
    })
    返回 项们
}

函数 main() -> 整数 {
    私有 数组[字符串] 参数 = std.os.参数()
    如果 #参数 << 2 就 {
        std.io.写错误("用法：词频 <文件>")
        返回 1
    }

    私有 结果[字符串, 字符串] 读 = std.fs.读取文件(参数[1])
    匹配 读 {
        例 失败(原因): {
            std.io.写错误("读取失败：" .. 原因)
            返回 1
        }
        例 成功(文本): {
            私有 映射[字符串, 整数] 表 = 统计(借用 文本)
            私有 数组[词频项] 榜 = 排行(借用 表)

            私有 整数 前 = 10
            如果 #榜 << 前 就 { 前 = #榜 }
            对 i: 0~(前 - 1) {
                std.io.打印行(榜[i].词 .. "：" .. 字符串(榜[i].次数))
            }
            返回 0
        }
    }
}
```

### 17.2 示例二：JSON 解析器（递归下降）

覆盖：递归枚举、可变借用、字符串下标、失败传播、解构匹配。

```简言
模块 JSON

引入 std.io
引入 std.string
引入 std.array
引入 std.map
引入 std.fs

枚举 值 {
    空值
    布尔(内容: 布尔值)
    数字(内容: 浮点)
    文本(内容: 字符串)
    数组(项: 数组[值])
    对象(项: 映射[字符串, 值])
}

结构 解析器 {
    源: 字符串
    位置: 整数
}

函数 取字符(p: 借用 解析器) -> 字符串 {
    如果 p.位置 >= #p.源 就 { 返回 "" }
    返回 p.源[p.位置]
}

函数 前进(p: 可变借用 解析器) {
    p.位置 = p.位置 + 1
}

函数 跳过空白(p: 可变借用 解析器) {
    循环 {
        私有 字符串 c = 取字符(借用 p)
        如果 #c == 0 就 { 打断 }
        如果 c == " " 或 c == "\n" 或 c == "\r" 或 c == "\t" 就 {
            前进(可变借用 p)
        } 否则 {
            打断
        }
    }
}

函数 解析值(p: 可变借用 解析器) -> 结果[值, 字符串] {
    跳过空白(可变借用 p)
    私有 字符串 c = 取字符(借用 p)
    如果 #c == 0 就 { 返回 失败("输入意外结束") }

    匹配 c {
        例 "{": { 返回 解析对象(可变借用 p) }
        例 "[": { 返回 解析数组(可变借用 p) }
        例 "\"": { 返回 解析文本(可变借用 p) }
        例 "t": { 返回 解析字面("true", 值.布尔(真), 可变借用 p) }
        例 "f": { 返回 解析字面("false", 值.布尔(假), 可变借用 p) }
        例 "n": { 返回 解析字面("null", 值.空值, 可变借用 p) }
        默认: { 返回 解析数字(可变借用 p) }
    }
}

函数 解析字面(期望: 字符串, 结果值: 值, p: 可变借用 解析器) -> 结果[值, 字符串] {
    如果 (p.位置 + #期望) >> #p.源 就 {
        返回 失败("字面量不完整")
    }
    私有 字符串 片段 = std.string.子串(p.源, p.位置, p.位置 + #期望) 失败返回
    如果 片段 != 期望 就 { 返回 失败("期望 " .. 期望) }
    p.位置 = p.位置 + #期望
    返回 成功(结果值)
}

函数 解析文本(p: 可变借用 解析器) -> 结果[值, 字符串] {
    前进(可变借用 p)
    私有 字符串 缓冲 = ""
    循环 {
        私有 字符串 c = 取字符(借用 p)
        如果 #c == 0 就 { 返回 失败("字符串未闭合") }
        如果 c == "\"" 就 {
            前进(可变借用 p)
            返回 成功(值.文本(缓冲))
        }
        如果 c == "\\" 就 {
            前进(可变借用 p)
            私有 字符串 e = 取字符(借用 p)
            匹配 e {
                例 "n": { 缓冲 = 缓冲 .. "\n" }
                例 "t": { 缓冲 = 缓冲 .. "\t" }
                例 "\"": { 缓冲 = 缓冲 .. "\"" }
                例 "\\": { 缓冲 = 缓冲 .. "\\" }
                默认: { 返回 失败("未知转义") }
            }
            前进(可变借用 p)
        } 否则 {
            缓冲 = 缓冲 .. c
            前进(可变借用 p)
        }
    }
}

函数 解析数字(p: 可变借用 解析器) -> 结果[值, 字符串] {
    私有 整数 起 = p.位置
    循环 {
        私有 字符串 c = 取字符(借用 p)
        如果 #c == 0 就 { 打断 }
        如果 (c >= "0" 与 c <= "9") 或 c == "-" 或 c == "." 或 c == "e" 或 c == "E" 或 c == "+" 就 {
            前进(可变借用 p)
        } 否则 {
            打断
        }
    }
    如果 p.位置 == 起 就 { 返回 失败("不是数字") }
    私有 字符串 片段 = std.string.子串(p.源, 起, p.位置) 失败返回
    私有 浮点 数 = std.string.转浮点(片段) 失败返回
    返回 成功(值.数字(数))
}

函数 解析数组(p: 可变借用 解析器) -> 结果[值, 字符串] {
    前进(可变借用 p)
    私有 数组[值] 项们 = {}
    跳过空白(可变借用 p)
    如果 取字符(借用 p) == "]" 就 {
        前进(可变借用 p)
        返回 成功(值.数组(项们))
    }

    循环 {
        私有 值 v = 解析值(可变借用 p) 失败返回
        项们.追加(v)
        跳过空白(可变借用 p)
        私有 字符串 c = 取字符(借用 p)
        如果 c == "," 就 {
            前进(可变借用 p)
        } 否则 如果 c == "]" 就 {
            前进(可变借用 p)
            打断
        } 否则 {
            返回 失败("数组格式错误")
        }
    }
    返回 成功(值.数组(项们))
}

函数 解析对象(p: 可变借用 解析器) -> 结果[值, 字符串] {
    前进(可变借用 p)
    私有 映射[字符串, 值] 表 = {}
    跳过空白(可变借用 p)
    如果 取字符(借用 p) == "}" 就 {
        前进(可变借用 p)
        返回 成功(值.对象(表))
    }

    循环 {
        跳过空白(可变借用 p)
        私有 值 键值 = 解析文本(可变借用 p) 失败返回
        私有 字符串 键 = ""
        匹配 键值 {
            例 文本(s): { 键 = s }
            默认: { 返回 失败("键必须是字符串") }
        }
        跳过空白(可变借用 p)
        如果 取字符(借用 p) != ":" 就 { 返回 失败("缺少冒号") }
        前进(可变借用 p)

        私有 值 v = 解析值(可变借用 p) 失败返回
        表.插入(键, v)

        跳过空白(可变借用 p)
        私有 字符串 c = 取字符(借用 p)
        如果 c == "," 就 {
            前进(可变借用 p)
        } 否则 如果 c == "}" 就 {
            前进(可变借用 p)
            打断
        } 否则 {
            返回 失败("对象格式错误")
        }
    }
    返回 成功(值.对象(表))
}

函数 解析(源: 字符串) -> 结果[值, 字符串] {
    私有 解析器 p = { 源, 0 }
    私有 值 v = 解析值(可变借用 p) 失败返回
    跳过空白(可变借用 p)
    如果 p.位置 != #p.源 就 { 返回 失败("多余内容") }
    返回 成功(v)
}

函数 格式化(v: 借用 值) -> 字符串 {
    匹配 v {
        例 空值: { 返回 "null" }
        例 布尔(b): {
            如果 b 就 { 返回 "true" }
            返回 "false"
        }
        例 数字(n): { 返回 字符串(n) }
        例 文本(s): { 返回 "\"" .. s .. "\"" }
        例 数组(项): {
            私有 数组[字符串] 段 = {}
            对 x 在 项 {
                段.追加(格式化(借用 x))
            }
            返回 "[" .. std.string.连接(段, ", ") .. "]"
        }
        例 对象(项): {
            私有 数组[字符串] 段 = {}
            对 k, x 在 项 {
                段.追加("\"" .. k .. "\": " .. 格式化(借用 x))
            }
            返回 "{" .. std.string.连接(段, ", ") .. "}"
        }
    }
}

函数 main() -> 整数 {
    私有 结果[字符串, 字符串] 读 = std.fs.读取文件("data.json")
    匹配 读 {
        例 失败(原因): {
            std.io.写错误("读取失败：" .. 原因)
            返回 1
        }
        例 成功(文本): {
            私有 结果[值, 字符串] r = 解析(文本)
            匹配 r {
                例 成功(v): {
                    std.io.打印行(格式化(借用 v))
                    返回 0
                }
                例 失败(原因): {
                    std.io.写错误("解析失败：" .. 原因)
                    返回 1
                }
            }
        }
    }
}
```

### 17.3 示例三：并发文件统计（线程池 + 通道）

覆盖：线程、通道、跨线程移动、`可空` 关闭检测、结构构造。

```简言
模块 并发统计

引入 std.io
引入 std.string
引入 std.os
引入 std.fs

结构 任务 {
    编号: 整数
    路径: 字符串
}

结构 结果项 {
    编号: 整数
    字节数: 整数
    成功: 布尔值
}

函数 处理(任务项: 借用 任务) -> 结果项 {
    私有 结果[字符串, 字符串] 读 = std.fs.读取文件(任务项.路径)
    匹配 读 {
        例 成功(内容): { 返回 { 任务项.编号, #内容, 真 } }
        例 失败(原因): { 返回 { 任务项.编号, 0, 假 } }
    }
}

函数 main() -> 整数 {
    私有 通道[任务] 任务们 = 通道[任务](1024)
    私有 通道[结果项] 结果们 = 通道[结果项](64)
    私有 常量 整数 工人数 = 4

    -- 启动工人线程
    对 n: 1~工人数 {
        线程 {
            循环 {
                私有 可空[任务] 可能 = 接收 任务们
                如果 可能 == 空 就 { 打断 }
                私有 任务 t = 可能.取值()
                发送 结果们, 处理(借用 t)
            }
        }
    }

    -- 派发任务
    私有 数组[字符串] 参数 = std.os.参数()
    私有 整数 总数 = 0
    对 i: 1~(#参数 - 1) {
        发送 任务们, { i, 参数[i] }
        总数 = 总数 + 1
    }
    关闭 任务们

    -- 汇总结果
    私有 整数 完成 = 0
    私有 整数 总字节 = 0
    循环 {
        私有 可空[结果项] 可能 = 接收 结果们
        如果 可能 == 空 就 { 打断 }
        私有 结果项 r = 可能.取值()
        如果 r.成功 就 {
            总字节 = 总字节 + r.字节数
        } 否则 {
            std.io.写错误("任务失败：" .. 字符串(r.编号))
        }
        完成 = 完成 + 1
        如果 完成 == 总数 就 { 打断 }
    }

    std.io.打印行("处理 " .. 字符串(完成) .. " 个文件，共 " .. 字符串(总字节) .. " 字节")
    返回 0
}
```

> 通道容量说明：任务通道设为 1024，保证主线程派发时不会因工人卡在结果通道上而互锁。生产级实现应改为“派发线程 + 背压”。

## 18. 语法分析与解析器

> 本章记录 v0.1 解析器的实现方式与实测指标，并说明实现过程中发现的三处规范缺口。
> 规范是"应该怎样"，本章是"现在怎样"。

### 18.1 位置

```
源码 ──词法分析──► 词序列 ──语法分析──► 语法树 ──语义分析──► 带类型的树 ──► 代码生成
```

语法分析只做两件事：

1. 判断词的**顺序**是否符合本规范的文法；
2. 搭出语法树，给后面的类型检查与代码生成用。

它**不做**的事：不查名字是否重复、不查类型是否匹配、不查借用是否合法。这些属于语义分析。

### 18.2 做法：递归下降 + 预切词

| 决定 | 理由 |
|---|---|
| 递归下降（一条规则一个函数） | 与 EBNF 一一对应，改语法时改一处就够 |
| 先把全部词切进数组 | 需要"往前看两个词"判断声明/赋值；数组里看只是读下标 |
| 单遍，不建索引，只有一处回溯 | 回溯只用在 `函数(` 开头区分"函数类型声明"与"匿名函数" |
| 类型在解析时归一化成文字 | `数组[T]` 与 `T 组` 统一成 `T 组`，后面只需处理一种形态 |
| 节点不复制源码文字 | 记"起点 + 长度"，整个解析过程零字符串拷贝 |

### 18.3 优先级

EBNF 的表达式层是一条产生式链，实现就是一条函数调用链：**调用得越深，绑得越紧**。
完整优先级见 4.2 节；`^` 与 `=` 右结合，其余二元运算左结合。

### 18.4 错误与恢复

报错必须回答三件事：**在哪儿**（行列 + 原文 + 箭头）、**错在什么**（期望什么）、**实际看到啥**。

```
示例.简:20:18: 语法错误：这里应该写 `{`（一块代码要用 { 开头），实际是 换行
  20 |     函数 面积() -> 浮点
                                    ^
```

恢复策略：

| 情形 | 处理 |
|---|---|
| 期望某个词但没看到 | 报一次错，不消耗当前词，交给上层决定 |
| 一行内连续出错 | 跳到行尾，一行只报一次 |
| 一整行无法解析 | 报"这一句看不懂"并强制吃掉一个词，保证不死循环 |
| 块没闭合 | 在文件结尾报"要用 } 收尾" |

### 18.5 实测

输入 8.4 MB 源码（216 万词，每轮 104 万节点）：

| 编译方式 | 体积 | 吞吐 | 每秒词数 |
|---|---|---|---|
| `-O0` | 120 KB | 35.4 MB/s | 930 万 |
| `-O3 -flto -s` | 84 KB | **68.6 MB/s** | **1798 万** |
| musl `-Oz` 静态 | **66.5 KB** | 35.2 MB/s | 924 万 |
| musl `-O3` 静态 | 87 KB | 41.8 MB/s | 1096 万 |
| Python 参考实现 | — | 1.26 MB/s | 30 万 |

对照：GCC 解析 C 约 1–5 MB/s，Clang 约 10–20 MB/s。

### 18.6 实现中补的三处缺口

写解析器时发现规范有三处自相矛盾或缺失，**已按"让示例能跑通"的原则补进本规范**：

| 缺口 | 原文问题 | 处理 |
|---|---|---|
| `通道[T]` 不是类型 | 11.4 示例写 `通道[整数] 管道 = ...`，但 2.2 的类型表里没有它 | 补为 `通道类型`，既是类型也是构造 |
| `循环` 不在关键字表 | 11.4 与示例程序都用 `循环 { }`，1.4 关键字表与 EBNF 都没有 | 补为关键字与 `循环语句`，等价于 `当 真 就 { }` |
| 位运算残留中文别名 | 1.4 写着 `位非` 是中文别名，与第 60 轮"位运算改用符号"的决定冲突 | 删除别名，只保留符号 |

### 18.7 带名字的结构体字面量：定了，用 `新建`

EBNF 原文写作 `结构字面量 = [ 标识符 ] "{" ... "}"`，即允许 `点{ 1, 2 }`。
但这样写与控制流的花括号**无法区分**：

```
匹配 读 {          -- 这个 { 是匹配体，还是"读"的结构体字面量？
如果 条件 就 {      -- 同上
```

当时的临时处理是只支持无名字面量 `{ 1, 2 }`，靠左边的声明类型反推是哪个结构体。
这能覆盖 `点 p = {1, 2}`，但覆盖不了表达式位置：

```简言
返回 {1.0, 2.0}              -- 能，靠函数返回类型
组.追加({1.0, 2.0})          -- 能，靠形参类型
打印({1.0, 2.0})             -- 不能，没有上下文
```

**2026 年这一版拍板：加 `新建` 关键字。**

```简言
私有 点 a = 新建 点{ x: 1.0, y: 2.0 }   -- 按名字，顺序随便
私有 点 b = 新建 点{ 1.0, 2.0 }         -- 按声明顺序
返回 新建 点{ ... }                      -- 表达式位置也能写
```

规则：

| 项 | 规定 |
|---|---|
| 关键字 | `新建` 已加入 1.4 关键字表 |
| 类型名 | 必须是一个已经定义过的结构体；泛型结构的实参暂不支持 |
| 字段写法 | 两种混用都允许：先按 `名: 值` 填，剩下的空位再按顺序补 |
| 缺省 | 没给的字段自动清零（C 的复合字面量语义） |
| 重名 | 同一字段给两次是错误 |
| 多余 | 位置式给多了是错误；名字式给了不存在的字段是错误 |

为什么不做成 `点.新建(...)`？因为那要求每个结构体都自带一个构造函数，
等于让"声明一个类型"变成"写两个东西"。关键字更便宜，也更像中文。

### 18.8 v0.1 明确不支持

| 项 | 说明 |
|---|---|
| 符号表 / 作用域检查 | 名字重复不报错 |
| 类型检查 | `1 + "字符串"` 能过 |
| 泛型约束校验 | `[T: 可比较]` 只记录，不验证 |
| 借用检查 | 只解析 `借用` 标记，不验证生命周期 |
| 模式解构 | `例 失败(原因):` 整体按文本保存，`原因` 未绑定 |
| 控制流合法性 | `打断` 写在循环外不报错 |

## 19. 编译产物、体积与性能

> 本章是硬指标，不是愿望。每一条都有实测数据支撑。

### 18.1 产物形态：原生二进制

简言**编译成目标机器的原生可执行文件**（Linux 上是 ELF，Windows 上是 PE），
不打包解释器、不打包虚拟机、不打包运行时库。

```
源/*.简  ──简 构建──►  程序（单个可执行文件，双击即跑）
```

| 项 | 规定 |
|---|---|
| 目标 | x86-64 / ARM64 原生机器码 |
| 链接 | 默认**静态链接**，拷到同架构任何机器直接运行 |
| 依赖 | 零运行时依赖；不用 libc 之外的任何库 |
| 启动 | 不初始化 GC、不加载元数据，`main` 之前几乎不做事 |

### 18.2 不要求可逆

编译产物**不需要**能还原成简言源码。据此可以做下面这些事，全部允许：

| 允许 | 说明 |
|---|---|
| 剥离符号 | 函数名、变量名、类型名一律不保留 |
| 内联与折叠 | 小函数直接展开，常量直接算掉 |
| 删除未使用代码 | 包括整个模块 |
| 不保留 AST / 词法单元 | 中间产物只服务编译，不落盘 |
| 改名混淆 | 名字在二进制里无意义 |

**唯一可选保留的是行号表**（`--保留行号`），用于崩溃时打印 `第 42 行`。
即使保留，也只是"行号 → 地址"的单向映射，反推不出源码。

> 这条直接决定了体积和速度的下限：没有元数据要照顾，编译器可以放开手优化。

### 18.3 体积目标

| 程序 | 目标 | 说明 |
|---|---|---|
| 空程序（只有 `main`） | **< 20 KB** | 静态链接、stripped |
| Hello world | **< 50 KB** | 含格式化输出 |
| 词频统计示例 | **< 100 KB** | 含文件、字符串、映射 |

依据：本仓库的词法分析器（400 行 C，含文件读取、UTF-8 解码、哈希表、
格式化输出、性能测试）用 musl 静态链接实测 **37 KB**。语言运行时只要不比它更重，
上面的目标就有余量。

对照——同一个程序，换链接方式体积差 20 倍：

| 方式 | 体积 |
|---|---|
| gcc 动态链接 glibc | 24 KB |
| gcc 静态链接 glibc | 705 KB |
| **musl 静态链接** | **37 KB** |

结论写进工具链：**默认用 musl（或等价的精简运行库）静态链接**，不要用 glibc 静态。

### 18.4 速度目标

| 指标 | 目标 |
|---|---|
| 纯计算循环 | 与 C 差距 **< 10%** |
| 函数调用 | 零开销（单态化 + 内联），无虚表跳转 |
| 内存分配 | 栈上分配优先；堆分配走 arena，无锁 |
| 启动时间 | < 5 ms |
| 词法分析 | > 300 MB/s（实测 500 MB/s，见下） |

保证这些的数条设计已在前面章节定死：

| 设计 | 带来的零开销 |
|---|---|
| 单态化泛型 | 无运行时类型分发 |
| 所有权 + 借用 | 无 GC、无引用计数、无运行时检查 |
| `可空` / `结果` | 无异常表、无栈展开 |
| 接口静态分发优先 | 无虚表（`动态[接口]` 才用） |
| 无反射、无 RTTI | 二进制里没有类型信息 |

### 18.5 实测：一个真实的简言组件

`词法分析器`（本仓库 `词法/lexer.c`，用 C 实现，作为语言工具链的性能基线）：

| 编译方式 | 体积 | 吞吐 |
|---|---|---|
| `-O0` | 35 KB | 111 MB/s |
| `-O2` | 27 KB | 440 MB/s |
| `-O3 -flto -s` | 24 KB | 502 MB/s |
| musl `-Oz` 静态 | 37 KB | 413 MB/s |
| musl `-O3` 静态 | 39 KB | 483 MB/s |

输入为 18 MB 中文为主的简言源码，平均每 5 个字节产生一个词。
换成 3 KB 的示例文件（词密度极高），吞吐仍在 500 MB/s 量级。

**这条基线就是简言编译器的及格线**：自己写的词法器如果慢于 300 MB/s，说明实现有问题。

### 18.6 路线

| 阶段 | 产物 | 用途 |
|---|---|---|
| v0.1 | 树遍历解释器 | 引导：先把语言跑通，不求快 |
| v0.2 | 字节码 + 栈式 VM | 过渡：验证语义，方便调试 |
| **v1.0** | **原生 AOT** | **交付形态：上面的体积与速度指标在这一阶段兑现** |

解释器和 VM 只是为了"能自己编译自己"的过渡产物。
一旦 AOT 后端可用，解释器不再随发行版提供。

## 20. 附录 A：完整 EBNF

> 约定：`{ X }` 0 次或多次，`[ X ]` 可选，`|` 或。

```ebnf
(* ===== 程序与模块 ===== *)
程序        = 模块声明 { 顶层声明 } ;
模块声明    = "模块" 标识符 换行 ;
顶层声明    = [ "私有" ] ( 引入 | 导出 | 函数声明 | 结构声明 | 枚举声明
            | 接口声明 | 实现声明 | 常量声明 | 变量声明 | 令声明
            | 测试声明 | 编译期函数 | 宏声明 | 外部声明 ) ;

引入        = "引入" 模块路径 [ "为" 标识符 ] [ "{" 标识符列表 "}" ] 换行 ;
导出        = "导出" 模块路径 换行 ;
```

## 21. 附录 B：决策速查

| 决策 | 结论 |
|---|---|
| 语法骨架 | 仿 C，中文关键字，半角符号，块必须 `{}`，无分号 |
| 默认可变 | 是，`不可变` 只读 |
| 除法 | `/` 返回浮点；`//` 整除；`%` 取余 |
| 乘方 | `^`，右结合，优先级高于一元负号 |
| 比较 | `<<` `>>` `<=` `>=`（`<<` 是小于，不是移位） |
| 位运算 | `&` `\|` `^^` `~~` `<<<` `>>>`，冲突即双写 |
| 复合赋值 | 不支持 |
| 字符串拼接 | `..`，仅字符串与字符串 |
| 长度 | `#` |
| 整数宽度 | 默认 64 位，另有 `整数8/16/32/64` |
| 泛型约束 | `[T: 可比较]`，与 `实现 X 为 Y` 区分 |
| 泛型实现 | 单态化，零开销 |
| 匿名函数 | `函数(x) -> 类型 {}`，`\|x\|` 不可用（与按位或冲突） |
| 接口 | 默认方法、`继承`、`自身`、多接口实现 |
| 顶层可见性 | 默认公开，`私有` 收窄 |
| 内存 | 所有权 + 借用，编译期释放，无 GC |
| 错误 | `可空` + `结果`，`失败返回`，无异常 |
| 并发 | 线程 + 通道 + 异步，跨线程禁借用 |
| 标准库 | 全中文命名，`模块.函数` |
| 编译产物 | 原生二进制，静态链接，零运行时依赖 |
| 可逆性 | 不要求，允许 strip / 内联 / 混淆 |
| 体积目标 | 空程序 < 20 KB，Hello world < 50 KB |
| 速度目标 | 与 C 差距 < 10% |
| 执行模型 | 解释器(引导) → 字节码 VM(过渡) → 原生 AOT(v1.0 交付) |
| 工具 | `简 新建/构建/运行/测试/格式/检查/交互` |
| 指针 | 暂不设计，FFI 用不透明句柄 |
| 通道 | `通道[T]` 既是类型也是构造 |
| 循环 | `循环 { }`，等价 `当 真 就 { }` |
| 结构体字面量 | v0.1 只支持无名 `{ a, b }`，带名构造待定 |
