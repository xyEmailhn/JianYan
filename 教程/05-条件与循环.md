# 第 5 章 · 条件与循环

> `如果 条件 就 { }`——`就` 是这一句的骨架，不能省。

## 5.1 完整代码

`教程/例子/05-条件与循环.jy`：

```简言
模块 教程.控制流

函数 评级(分: 整数) -> 字符串 {
    如果 分 >= 90 就 {
        返回 "优秀"
    } 否则如果 分 >= 60 就 {
        返回 "及格"
    } 否则 {
        返回 "不及格"
    }
}

函数 主() -> 整数 {
    打印("95 → ") 打印行(评级(95))
    打印("72 → ") 打印行(评级(72))
    打印("40 → ") 打印行(评级(40))

    私有 整数 和 = 0
    私有 整数 i = 1
    当 i <= 100 就 {
        和 = 和 + i
        i = i + 1
    }
    打印("1..100 = ") 打印行(和)

    私有 整数 奇位和 = 0
    对 k: 1~10, 步长: 2 {
        奇位和 = 奇位和 + k
    }
    打印("1,3,5,7,9 = ") 打印行(奇位和)

    私有 整数 组 数 = {4, 8, 15, 16}
    私有 整数 最大数 = 数[0]
    对 x 在 数 {
        如果 x >> 最大数 就 { 最大数 = x }
    }
    打印("最大 ") 打印行(最大数)

    私有 整数 找到 = -1
    对 n: 1~100 {
        如果 n % 7 != 0 就 { 继续 }
        如果 n >> 20 就 { 打断 }
        找到 = n
    }
    打印("20 以内最后一个 7 的倍数 ") 打印行(找到)

    私有 整数 次 = 0
    循环 {
        次 = 次 + 1
        如果 次 >= 3 就 { 打断 }
    }
    打印("循环了 ") 打印行(次)
    返回 0
}
```

```
95 → 优秀
72 → 及格
40 → 不及格
1..100 = 5050
1,3,5,7,9 = 25
最大 16
20 以内最后一个 7 的倍数 14
循环了 3
```

## 5.2 如果

```简言
如果 条件 就 {
    ...
} 否则如果 另一个条件 就 {
    ...
} 否则 {
    ...
}
```

三条硬规则：

1. `就` 不能省，`否则如果` 后面也要 `就`。
2. `否则` 后面**不写** `就`，直接 `{`。
3. 条件必须是 `布尔值`。`如果 1 就` 编不过——C 那边"非零即真"的习惯在这里行不通。

`否则如果` 写得再多也不会嵌套成悬崖，因为每个分支都平铺在同一个缩进上。
真需要嵌套就老实缩进，或者把它拆成一个函数：

```简言
函数 评级(分: 整数) -> 字符串 {
    如果 分 >= 90 就 { 返回 "优秀" }
    如果 分 >= 60 就 { 返回 "及格" }
    返回 "不及格"
}
```

这种"早返回"的写法通常比 `否则如果` 链更好读：每条规则一行，从上往下命中即走。

## 5.3 当（while）

```简言
私有 整数 i = 1
当 i <= 100 就 {
    和 = 和 + i
    i = i + 1
}
```

`当` 和 `如果` 长得一样，区别只有"回到开头再判一次"。

## 5.4 对（for）

三种形态：

```简言
对 i: 1~10 { ... }                  -- 闭区间，1 到 10 都走
对 i: 0~n, 步长: 2 { ... }          -- 从 0 开始，每次加 2
对 x 在 组 { ... }                  -- 遍历组里的每个元素
```

注意范围用的是 `~` 不是 `..`。`..` 是字符串拼接，两个数字写 `1..10` 会报
"`..` 只能拼字符串"。

`对 x 在 组` 的 `x` 是元素本身（如果元素是字符串、结构这类"有所有权"的值，
语义层会提示你写 `借用 x`，因为它默认按值搬走）。

## 5.5 循环（无限循环）

```简言
循环 {
    如果 该走了 就 { 打断 }
}
```

`循环 { }` 等价于 `当 真 就 { }`。用途是"出口在中间"的场景：

```简言
私有 整数 已处理 = 0
循环 {
    如果 已处理 >= 总量 就 { 打断 }
    处理(已处理)
    已处理 = 已处理 + 1
}
```

## 5.6 打断与继续

| 语句 | 作用 |
|---|---|
| `打断` | 跳出**最近一层**循环 |
| `继续` | 跳过本轮剩下的，进入下一轮 |

它们只作用于循环，写在循环外会报错：

```
[错误] `打断` 只能写在循环里，这里不在任何循环中
```

嵌套循环里 `打断` 只跳一层。要跳两层，用一个布尔标志：

```简言
私有 布尔值 该停 = 假
对 i: 1~9 {
    如果 该停 就 { 打断 }
    对 j: 1~9 {
        如果 i * j >> 40 就 {
            该停 = 真
            打断
        }
    }
}
```

## 5.7 条件里不要写赋值

简言没有"赋值表达式"，`如果 x = 5 就` 是语法错误。这是好事：C 里
`if (x = 5)` 和 `if (x == 5)` 打错一个字符就可能查一整天。

## 5.8 小结

| 结构 | 写法 |
|---|---|
| 条件 | `如果 c 就 { } 否则如果 c2 就 { } 否则 { }` |
| 当循环 | `当 c 就 { }` |
| 范围循环 | `对 i: 起~止 { }`，可加 `, 步长: k` |
| 遍历 | `对 x 在 组 { }` |
| 无限循环 | `循环 { }` |
| 跳出 / 下一轮 | `打断` / `继续` |
