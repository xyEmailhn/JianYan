# 第 2 章 · 变量与类型

> 简言不做隐式转换。这条规矩听起来麻烦，实际上省掉了"这个数是整数还是浮点"的全部猜测。

## 2.2 基本类型只有这几种

| 类型 | 是什么 | 例子 |
|---|---|---|
| `整数` | 64 位有符号，-2⁶³ ~ 2⁶³-1 | `42`、`-7`、`0x1F` |
| `浮点` | 64 位 IEEE754（就是 C 的 `double`） | `3.14`、`1e9` |
| `布尔值` | 只有 `真` / `假` | `真` |
| `字符串` | UTF-8 序列，不可变，长度按**字符**算 | `"你好"`、`[[原样文本]]` |
| `空值` | 只有 `空` 一个值 | `空` |

这里没有"整数32/64"的选择焦虑：`整数` 就是 64 位。规范里还留着 `整数8/16/32` 的
名字，这一版只在类型表里登记，转换函数还没接，用不上。

## 2.3 声明：四种写法

```简言
常量 整数 一年天数 = 365          -- 编译期算完，此后不可改
整数 全局计数 = 0                 -- 顶层变量，默认公开
私有 整数 局部 = 1                -- 函数里必须写 私有
令 推导 = 42                      -- 让编译器看右边猜类型
不可变 整数 只读 = 10             -- 可改但不许改
```

| 修饰 | 作用 | 用在哪 |
|---|---|---|
| `常量` | 编译期求值，不占运行时空间 | 顶层 |
| `私有` | 仅本模块可见 / 函数局部变量 | 顶层或函数内 |
| `不可变` | 只读，赋值会报错 | 任意 |
| `令` | 类型推导，省掉写类型 | 有初值时 |

三条容易踩的规则：

1. **函数里的变量必须写 `私有`。** 漏了会报"找不到 xxx"，因为编译器会把它当成
   对已有变量的赋值，而不是新声明。
2. **`令` 不能用在函数参数和返回值上。** 那两处必须写类型，不然调用方没法检查。
3. **`常量` 必须能在编译期算完。** 不能读文件、不能调用户函数。

## 2.4 类型转换：都得写出来

```简言
私有 整数 取整 = 整数(3.99)      -- 3，向零截断
私有 整数 负数 = 整数(-3.99)     -- -3，不是 -4
私有 浮点 变浮点 = 浮点(7)        -- 7
私有 字符串 文本 = 字符串(42)     -- "42"
```

四条规矩：

| 转换 | 行为 |
|---|---|
| `整数(x)` | 丢掉小数部分，**向零**。`-3.99 → -3` |
| `浮点(x)` | 精确转换（整数范围内无损） |
| `字符串(x)` | 十进制文字，浮点按 `%g` 风格 |
| 字符串 → 数字 | 不用 `整数(s)`，用 `s.转整数()`，它返回 `结果`，失败有原因 |

为什么字符串转数字要用方法？因为 `"abc"` 转不了整数，`整数("abc")` 只能崩溃或者
返回个 0，两种都不好。`转整数()` 把"转不了"变成一种**正常返回值**，调用方必须处理。

## 2.5 字面量

```简言
私有 整数 十六 = 0x1F        -- 31
私有 整数 二进制 = 0b1010     -- 10
私有 整数 带下划线 = 1_000_000
私有 浮点 科学 = 1e9
私有 字符串 单行 = "第一行\n第二行"
私有 字符串 原样 = [[
    这里面的 \n 就是两个字符，不转义
]]
```

`[[ ... ]]` 是原样字符串，写路径、正则、多行文本时不用一路转义。

## 2.6 命名

- 中文、英文、数字、下划线都行，**不能以数字开头**。
- 区分大小写。
- **不能和关键字重名**：`类型`、`结果`、`匹配`、`接口`、`复制`、`空`、`循环` 这些都不行。
  连模块名也不行（`模块 教程.类型` 会被拒绝）。

关键字全是中文，所以写代码时有个天然的好处：**看到中文词先怀疑它是不是关键字**。
报错说"`xxx` 是语言保留的关键字"时，换个名字就好。

## 2.7 小结

| 想干什么 | 写法 |
|---|---|
| 常量 | `常量 整数 名 = 值` |
| 顶层变量 | `整数 名 = 值` |
| 局部变量 | `私有 整数 名 = 值` |
| 推导类型 | `私有 令 名 = 值` |
| 只读 | `不可变 整数 名 = 值` |
| 转换 | `整数(x)` `浮点(x)` `字符串(x)` |
