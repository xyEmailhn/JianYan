# 第 11 章 · 可空与结果

> 简言没有异常。可能"没有值"用 `可空`，可能"失败并且有原因"用 `结果`。
> 两者都不能直接取——编译器会把"没判就用"拦下来。

## 11.1 完整代码

`教程/例子/11-错误.jy`：

```简言
模块 教程.错误

函数 找下标(xs: 借用 整数 组, 目标: 整数) -> 可空[整数] {
    私有 整数 i = 0
    当 i << #xs 就 {
        如果 xs[i] == 目标 就 { 返回 i }
        i = i + 1
    }
    返回 空
}

函数 除(甲: 整数, 乙: 整数) -> 结果[整数, 字符串] {
    如果 乙 == 0 就 { 返回 失败("除数不能是 0") }
    返回 成功(甲 // 乙)
}

函数 先除再减(甲: 整数, 乙: 整数, 减数: 整数) -> 结果[整数, 字符串] {
    私有 结果[整数, 字符串] r = 除(甲, 乙)
    如果 r.是失败 就 { 返回 失败(r.错误值) }
    返回 成功(r.取值 - 减数)
}

函数 主() -> 整数 {
    私有 整数 组 数 = {10, 20, 30}
    私有 可空[整数] 位 = 找下标(借用 数, 20)
    如果 位 != 空 就 {
        打印("20 在下标 ") 打印行(位.取值())
    } 否则 {
        打印行("没找到")
    }
    打印("找 99 的结果 ") 打印行(找下标(借用 数, 99) == 空)
    打印("或默认兜底 ") 打印行(找下标(借用 数, 99).或默认(-1))

    私有 结果[整数, 字符串] 好 = 除(17, 5)
    如果 好.是成功 就 {
        打印("17 // 5 = ") 打印行(好.取值)
    }

    私有 结果[整数, 字符串] 坏 = 除(1, 0)
    如果 坏.是失败 就 {
        打印("失败原因：") 打印行(坏.错误值)
    }
    打印("失败时或默认 ") 打印行(坏.或默认(0))

    私有 结果[整数, 字符串] 链 = 先除再减(20, 4, 3)
    打印("20//4-3 = ") 打印行(链.取值)

    私有 结果[整数, 字符串] 断 = 先除再减(20, 0, 3)
    如果 断.是失败 就 { 打印("断在哪：") 打印行(断.错误值) }
    返回 0
}
```

```
20 在下标 1
找 99 的结果 真
或默认兜底 -1
17 // 5 = 3
失败原因：除数不能是 0
失败时或默认 0
20//4-3 = 2
断在哪：除数不能是 0
```

## 11.2 可空

```简言
函数 找下标(xs: 借用 整数 组, 目标: 整数) -> 可空[整数]
```

`可空[整数]` 的意思是"要么是一个整数，要么是 `空`"。返回值就两种写法：
`返回 i` 或者 `返回 空`。

三个操作：

| 写法 | 结果 | 什么时候用 |
|---|---|---|
| `x == 空` / `x != 空` | 布尔值 | 判有没有 |
| `x.取值()` | 里面的值，空时崩 | 已经确认有值 |
| `x.或默认(d)` | 有就给自己，空就给 d | 有合理的默认值 |

不判就用会编不过：

```简言
打印行(位.取值())     -- 错：
-- 这是 可空[整数]，可能为空，不能直接取 `.取值`。
-- 先写 如果 它 != 空 就 { ... }，或者写 它.取值()
```

这条报错很啰嗦，但它拦下的是空指针那一类崩溃。

**在 `如果 x != 空 就 { ... }` 的块里，x 可以直接 `.取值`。** 编译器记得这个判断，
不用再判一次：

```简言
如果 位 != 空 就 {
    打印行(位.取值())     -- 这里不会报错
}
```

## 11.3 结果

```简言
函数 除(甲: 整数, 乙: 整数) -> 结果[整数, 字符串] {
    如果 乙 == 0 就 { 返回 失败("除数不能是 0") }
    返回 成功(甲 // 乙)
}
```

`结果[成功类型, 错误类型]`。构造只有两种：`成功(值)` 和 `失败(原因)`。

| 操作 | 返回 | 说明 |
|---|---|---|
| `.是成功` / `.是失败` | `布尔值` | 成没成 |
| `.取值` | 成功类型 | 失败时崩，先判 |
| `.错误值` | 错误类型 | 取原因 |
| `.或默认(d)` | 成功类型 | 失败就给 d |

注意 **`.取值` 是可空和结果共用的名字**，但两者不能混：可空的 `取值` 是方法（要写括号），
结果的 `取值` 是属性（不写括号）。

```简言
位.取值()          -- 可空：带括号
好.取值            -- 结果：不带括号
```

记不住就记住这条：**可空是"容器套容器"，取值要调用；结果是"成败 + 载荷"，取值是读字段。**

## 11.4 往上传递

一个函数里调了另一个可能失败的函数，怎么办？两种写法：

```简言
-- 写法一：显式判，原样往上抛
函数 先除再减(甲: 整数, 乙: 整数, 减数: 整数) -> 结果[整数, 字符串] {
    私有 结果[整数, 字符串] r = 除(甲, 乙)
    如果 r.是失败 就 { 返回 失败(r.错误值) }
    返回 成功(r.取值 - 减数)
}
```

```简言
-- 写法二：失败就换一个默认值，不往外抛
函数 先除再减(甲: 整数, 乙: 整数, 减数: 整数) -> 整数 {
    返回 除(甲, 乙).或默认(0) - 减数
}
```

规范里还有一种 `表达式 失败返回` 的简写（失败就自动 `返回 失败(原因)`），
这一版还没接，写了会报"找不到 `失败返回`"。先用写法一，行为完全一样。

## 11.5 三种错误处理风格的取舍

| 风格 | 优点 | 缺点 |
|---|---|---|
| 崩溃（越界、除零） | 简单，不放过 bug | 线上跑着跑着挂掉 |
| `可空` | 逼你处理"没有" | 没有原因，不知道为啥没有 |
| `结果` | 有原因，能往上抛 | 每层都要判，代码变长 |

简言的建议：

- **"没有"是正常情况** → `可空`。例：查表、找下标、`取` 越界。
- **"失败"是异常情况，且调用方需要知道为什么** → `结果`。例：读文件、解析文本。
- **程序员写错了** → 让它崩。数组越界、除以零、`.取值()` 取到空，都直接终止。

## 11.6 小结

| 想干什么 | 可空 | 结果 |
|---|---|---|
| 构造 | `返回 空` / `返回 值` | `成功(v)` / `失败(e)` |
| 判断 | `x == 空` | `x.是成功` / `x.是失败` |
| 取值 | `x.取值()` | `x.取值` |
| 取原因 | — | `x.错误值` |
| 兜底 | `x.或默认(d)` | `x.或默认(d)` |
