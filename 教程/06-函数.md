# 第 6 章 · 函数

> 参数类型必须写。只读的传 `借用`，要改调用方那份传 `可变借用`。别的语言里那些
> 声明拷贝语义的杂事，简言用两个词解决。

## 6.1 完整代码

`教程/例子/06-函数.jy`：

```简言
模块 教程.调用

函数 阶乘(n: 整数) -> 整数 {
    如果 n <= 1 就 { 返回 1 }
    返回 n * 阶乘(n - 1)
}

-- 函数体只有一个表达式时，可以写成 `= 表达式`
函数 平方(x: 整数) -> 整数 = x * x

-- 借用：不复制整组数据，函数里只能读
函数 求和(xs: 借用 整数 组) -> 整数 {
    私有 整数 和 = 0
    对 x 在 xs { 和 = 和 + x }
    返回 和
}

-- 可变借用：改的就是调用方那个组
函数 每个加一(xs: 可变借用 整数 组) {
    私有 整数 i = 0
    当 i << #xs 就 {
        xs[i] = xs[i] + 1
        i = i + 1
    }
}

结构 商余 {
    商: 整数
    余: 整数
}

函数 除(甲: 整数, 乙: 整数) -> 商余 {
    返回 新建 商余{ 甲 // 乙, 甲 % 乙 }
}

函数 主() -> 整数 {
    打印("10! = ") 打印行(阶乘(10))
    打印("平方(13) = ") 打印行(平方(13))

    私有 整数 组 数 = {1, 2, 3, 4}
    打印("求和 = ") 打印行(求和(借用 数))

    每个加一(可变借用 数)
    打印("加一后第一个 = ") 打印行(数[0])

    私有 商余 r = 除(17, 5)
    打印("17 // 5 = ") 打印(r.商) 打印(" 余 ") 打印行(r.余)
    返回 0
}
```

```
10! = 3628800
平方(13) = 169
求和 = 10
加一后第一个 = 2
17 // 5 = 3 余 2
```

## 6.2 声明与返回

```简言
函数 名字(参数: 类型, 参数2: 类型) -> 返回类型 {
    ...
    返回 值
}
```

| 规则 | 说明 |
|---|---|
| 参数类型 | **必须写**，不允许推导 |
| 返回类型 | `-> 类型`；没有返回值就整个省略 |
| 没有返回值 | 函数体里写 `返回` 也行，写 `返回 值` 不行 |
| 表达式体 | `函数 f(x: 整数) -> 整数 = x * x`，适合一行能算完的 |
| 重载 | 不支持。要不同行为就换名字或用泛型 |
| 嵌套函数 | 不支持。要拆小就放顶层 |

**有返回类型的函数，每条路都得返回。** 漏一条会得到提示：

```
[提示] 这个函数声明返回 整数，但不是所有路都会 `返回`。漏了的那条路会返回空值
```

## 6.3 借用：不复制，只读

```简言
函数 求和(xs: 借用 整数 组) -> 整数 { ... }

求和(借用 数)
```

为什么要写 `借用`？因为组、字符串、结构这些类型默认按值传递——传进去就搬走了，
调用方手里那个变量就没了。`借用` 说"我只是看看，不拿走"。

调用处也要写 `借用`，这是刻意的：**看到 `借用 数` 就知道这行不会改 数**。

```简言
函数 平均(xs: 借用 整数 组) -> 浮点 {
    私有 整数 和 = 0
    对 x 在 xs { 和 = 和 + x }
    返回 浮点(和) / 浮点(#xs)
}
```

## 6.4 可变借用：真的能改到调用方

```简言
函数 每个加一(xs: 可变借用 整数 组) {
    ...
    xs[i] = xs[i] + 1
}

每个加一(可变借用 数)
打印行(数[0])   -- 2，不是 1
```

`可变借用` 在 C 里就是一个指针，`xs[i] = ...` 改的是调用方那块内存。
不加修饰地传 `可变借用` 会编译报错，这条约束挡住的是"以为改了其实改的是副本"。

同一条规矩也用在结构上：

```简言
函数 平移(p: 可变借用 点, dx: 浮点, dy: 浮点) {
    p.x = p.x + dx
    p.y = p.y + dy
}
```

## 6.5 多返回值：用结构包

简言没有元组解构返回值，多个值就定义一个结构：

```简言
结构 商余 {
    商: 整数
    余: 整数
}

函数 除(甲: 整数, 乙: 整数) -> 商余 {
    返回 新建 商余{ 甲 // 乙, 甲 % 乙 }
}
```

`新建 商余{ ... }` 里的 `新建` 不能省——在 `返回` 这种表达式位置，
裸写 `商余{ ... }` 会和代码块的花括号撞车（见[第 18 章](18-报错速查.md)）。

## 6.6 递归

```简言
函数 阶乘(n: 整数) -> 整数 {
    如果 n <= 1 就 { 返回 1 }
    返回 n * 阶乘(n - 1)
}
```

没有尾调用优化，`阶乘(100000)` 会把栈撑爆。真要跑那么深就改写成循环：

```简言
函数 阶乘(n: 整数) -> 大整数 {
    私有 大整数 果 = 大数(1)
    私有 整数 i = 2
    当 i <= n 就 {
        果 = 果.乘(大数(i))
        i = i + 1
    }
    返回 果
}
```

## 6.7 参数是复制还是借用

| 参数类型 | 传参时发生什么 | 什么时候用 |
|---|---|---|
| `整数` `浮点` `布尔值` | 复制，随便改不影响外面 | 小值 |
| `大整数` `小数` | 复制指针（它们不可变，安全） | 大数运算 |
| `图` `声音` | 复制句柄（共享同一份数据） | 媒体 |
| `借用 T` | 借出去看，不许改 | 大结构的只读参数 |
| `可变借用 T` | 借出去改 | 就地修改 |
| 不加修饰的 `T`（组/结构/字符串） | **移动**，调用方不能再用了 | 交出所有权 |

最后一条是规范里的语义：不加修饰地传组/结构，所有权就交出去了。这一版
**只提示、不强制**，会看到：

```
[提示] `数据` 作为值参数传进去了，它的所有权会转给函数；如果后面还要用，请写 `借用 数据`
```

提示是给你看的，不是给编译器看的。养成习惯：**大块数据一律 `借用`**，
既清楚又不复制，比记住"这一版拦不拦"省心。

## 6.8 小结

| 想干什么 | 写法 |
|---|---|
| 定义 | `函数 名(a: 类型) -> 返回类型 { }` |
| 一行函数 | `函数 名(a: 类型) -> 类型 = 表达式` |
| 只读传参 | `借用 x` |
| 就地修改 | `可变借用 x` |
| 多个返回值 | 定义结构 + `新建 结构{...}` |
