# 第 15 章 · 报错速查

> 这一章不按语法组织，按**你看到的报错**组织。查到那句红字，改一行就好。

## 15.1 语法类

| 报错 | 原因 | 改法 |
|---|---|---|
| `这里应该写 {（一块代码要用 { 开头），实际是 换行` | `如果`/`当`/`函数` 后面少了 `{` | 补 `{`，并检查 `就` 写没写 |
| `这里需要一个名字（字段名），实际是 ,` | 结构/枚举的字段之间加了逗号 | 一行一个，不写逗号 |
| `这里需要一个表达式，实际是 ;` | 写了分号 | 删掉，简言没有分号 |
| `这里应该写 (，实际是 （` | 用了全角括号 | 切回半角符号 |
| `` `xxx` 是语言保留的关键字，不能当名字用 `` | 变量/函数/模块名撞了关键字 | 换个名字；模块名也算 |
| `顶层只能写 模块 / 引入 / 函数 / ...` | 语句写在了函数外面 | 包进函数里，或者改成顶层声明 |

## 15.2 名字与类型

| 报错 | 原因 | 改法 |
|---|---|---|
| `找不到 x。是不是拼错了，或者忘了在这之前声明？` | 变量没声明就在用 | 函数里补 `私有 类型 x = ...`；注意函数内必须写 `私有` |
| `不认识的类型 xxx` | 类型名拼错，或者结构/枚举定义在后面 | 检查拼写；定义放到使用之前 |
| `初值类型和声明的类型对不上：这里要 字符串 组，给的是 字符串` | 少了 `组`，或者该转换没转 | 类型写全；数字与字符串之间写 `字符串(x)` / `整数(x)` |
| `参数个数不对：这个函数要 2 个，这里给了 3 个` | 实参多给或少给 | 数一遍签名 |
| `这个函数声明返回 整数，但不是所有路都会 返回` | 有分支没返回 | 每条路补 `返回`，或者在末尾兜一句 |

## 15.3 运算符

| 报错 | 原因 | 改法 |
|---|---|---|
| `` `..` 只能拼字符串，左边是 整数，右边是 整数 `` | 拿 `..` 拼数字 | `"共 " .. 字符串(n) .. " 个"` |
| `` `%` 只能用在整数上 `` | 对浮点用了 `%` | 写 `甲 - 向下取整(甲 / 乙) * 乙` |
| `这里要 布尔值，给的是 整数` | `如果 1 就` 这种 | 写真正的比较：`如果 n != 0 就` |

## 15.4 可空与结果

| 报错 | 原因 | 改法 |
|---|---|---|
| `` 这是 可空[整数]，可能为空，不能直接取 `.取值` `` | 没判空就取 | `如果 x != 空 就 { ... x.取值() }`，或者 `x.或默认(0)` |
| `找不到 失败返回` | 这一版还没接 | 写成显式判断：`如果 r.是失败 就 { 返回 失败(r.错误值) }` |
| `后端还没实现方法：或默认` | 旧版本 | 已修。如果还遇到，先 `make` 一遍 |

## 15.5 结构、枚举、匹配

| 报错 | 原因 | 改法 |
|---|---|---|
| `这里需要一个表达式，实际是 自身` | 方法体里写了 `自身.r` | 这一版直接写 `r` |
| `找不到接口 形状` | `实现` 写在 `接口` 前面 | 接口先声明 |
| `` `圆` 不是接口，不能写在 `实现 … 为 …` 后面 `` | `实现 类型 为 接口` 写反了 | 顺序是"实现者 为 接口" |
| `匹配 没有处理 点，也没写 默认` | 漏了变体 | 补全，或者加 `默认: { }` |
| `找不到 圆` | 枚举变体省了前缀 | 写全：`形状.圆(2.0)` |

## 15.6 后端相关

| 报错 | 原因 | 改法 |
|---|---|---|
| `后端还没实现方法：xxx` | 方法名拼错，或这个方法在语义表里有、后端没接 | 对照[第 7 章](07-组与映射.md)、[第 4 章](04-字符串.md)的方法表核对名字 |
| `原生后端还不支持：这类类型的实参` | 用了 `-n`，但函数参数是字符串/结构/组 | 换回 C 后端，或者把参数改成整数 |
| `gcc 编译失败` + 一段 C 错误 | 通常意味着后端生成有问题 | 用 `-c` 把 C 导出来看；如果是 `v-1` 这种，多半是表达式位置写了裸结构字面量，加 `新建` |
| `undefined reference to 'xxx'` | 函数值变量被当成了函数名调用 | 这一版函数值还不能调用，改成直接调函数 |

## 15.7 这一版能用到什么程度

下面这些以前是"写得出来、跑不起来"，v0.14 全接上了：

| 功能 | 怎么写 | 说明 |
|---|---|---|
| `匹配` 字面量 / 范围 | `例 0:`、`例 1~9:`、`例 "红":`、`例 _:` | 非枚举的对象必须写 `默认` 或 `例 _` |
| 接口默认方法 | 接口里直接写函数体 | 实现方不写，就用接口里那份 |
| `失败返回` | `甲 失败返回` | 等价于 `如果 甲.是失败 就 { 返回 失败(甲.错误值) }` |
| 函数值 | `函数(整数) -> 整数 f = 函数(x: 整数) { ... }` | 能存、能传、能返回；**没有闭包** |
| `读入()` | `私有 字符串 行 = 读入()` | 读一行，去掉行尾换行；EOF 给空串 |
| `整数8/16/32` | `整数8(300)` → `44` | 真的按补码截断，不是摆设 |
| `对 k, v 在 映射` | 一次拿键和值 | 顺序由 `键组()` 定，和哈希布局无关 |
| `引入` | `引入 工具.数` → 同目录下 `工具/数.jy` | 名字进同一张表，没有模块隔离 |

还在路上、遇到别怀疑自己：

| 功能 | 现在是什么样 | 绕开 |
|---|---|---|
| `线程 { }` 真并发 | 块是顺序执行的，不会开新线程 | 通道本身能用，先写单线程 |
| 闭包 | 匿名函数抓不到外层局部变量，会明确报错 | 把它变成形参传进来 |
| `引入 … 为 别名` / `引入 …{甲, 乙}` | 报"这一版还没接" | 用整模块引入，名字直接写 |
| `匹配` 当表达式 | `私有 整数 x = 匹配 ...` 不认，`匹配` 是语句 | 先赋值再看，或者写函数 |
| 接口默认方法里用字段 | 默认方法只能用接口自己的方法 | 需要字段就在实现里重写一遍 |

## 15.8 排错的三个习惯

**一、先看第一个错误。** 后面的报错经常是第一个引起的连锁反应。修完第一个再编一次。

**二、把范围缩到最小。** 二十行的函数报错，删到五行还能复现，问题就在那五行里。

**三、用 `-c` 看后端生成了什么。** 语法语义都过了、C 编译却失败，说明是后端的问题：

```bash
./简编译 坏例子.jy -c /tmp/看.c
sed -n '/简言函数：主/,/^}/p' /tmp/看.c
```

生成的 C 相当直白——每个 IR 值一个变量，控制流用 `goto`。看懂它不难，
而且看一次就能明白"为什么这条语句生成了这样的代码"。

## 15.9 一句话

**报错是编译器在替你干活。** 简言的报错尽量写清"哪里错、为什么错、怎么改"，
遇到读不懂的，那多半是编译器的问题——记下来，去 `规范/` 里补一条。
