# 第 7 章 · 组与映射

> `组` 是能变长的数组，`映射` 是键值表。两者都带一套方法，用法和别的语言里的
> `Vec` / `HashMap`、`list` / `dict` 差不多，只是名字是中文。

## 7.1 完整代码

`教程/例子/07-容器.jy`：

```简言
模块 教程.容器

函数 主() -> 整数 {
    -- ---- 组 ----
    私有 整数 组 分数 = {88, 95, 72}
    打印("初始 ") 打印(#分数) 打印(" 个：")
    对 x 在 分数 { 打印(x) 打印(" ") }
    打印行("")

    分数.追加(100)
    分数.插入(0, 60)
    打印("增删后 ") 打印(#分数) 打印(" 个，第一个 ") 打印行(分数[0])

    分数.排序()
    打印("排序后：")
    对 x 在 分数 { 打印(x) 打印(" ") }
    打印行("")

    分数.反转()
    打印("反转后第一个 ") 打印行(分数[0])
    打印("包含 95？") 打印行(分数.包含(95))
    打印("删掉第一个，得到 ") 打印行(分数.删除(0))

    私有 可空[整数] 越界 = 分数.取(999)
    打印("越界取到空？") 打印行(越界 == 空)

    -- ---- 映射 ----
    私有 映射[字符串, 整数] 库存 = {"苹果": 12, "香蕉": 7}
    库存.插入("橙子", 20)
    打印("种类数 ") 打印行(库存.大小)
    打印("苹果 ") 打印行(库存.取("苹果").取值)

    对 名 在 库存.键组() {
        打印(名) 打印("=") 打印(库存.取(名).取值) 打印(" ")
    }
    打印行("")

    打印("删掉香蕉，原来有 ") 打印行(库存.删除("香蕉").取值)
    打印("现在种类数 ") 打印行(库存.大小)
    返回 0
}
```

```
初始 3 个：88 95 72 
增删后 5 个，第一个 60
排序后：60 72 88 95 100 
反转后第一个 100
包含 95？真
删掉第一个，得到 100
越界取到空？真
种类数 3
苹果 12
苹果=12 香蕉=7 橙子=20 
删掉香蕉，原来有 7
现在种类数 2
```

## 7.2 组：声明与构造

```简言
私有 整数 组 分数 = {88, 95, 72}
私有 字符串 组 名字 = {"张三", "李四"}
私有 浮点 组 空表 = {}
```

类型写法是 `元素类型 组`。**空的组必须靠左边的类型确定元素类型**，
`令 空表 = {}` 编不过——编译器不知道往里装什么。

定长数组也可以写 `整数 组[10]`，但它和动态组是两种东西，这一版用不上，先忘掉它。

## 7.3 组的下标与方法

```简言
分数[0]           -- 直接取，越界直接崩（快，但要自己保证不越界）
分数.取(0)        -- 安全版，返回 可空[整数]
#分数             -- 长度
```

| 方法 | 返回 | 说明 |
|---|---|---|
| `.长度` | `整数` | 同 `#组` |
| `.追加(x)` | — | 末尾加一个 |
| `.插入(i, x)` | — | 插到第 i 个位置，后面的往后挪 |
| `.删除(i)` | 元素 | 删掉第 i 个并返回它 |
| `.弹出` | `可空[T]` | 拿走最后一个 |
| `.取(i)` | `可空[T]` | 越界给 `空` |
| `.包含(x)` | `布尔值` | |
| `.排序` | — | 原地从小到大 |
| `.反转` | — | 原地倒过来 |
| `.复制` | `T 组` | 要一份副本，原的不动 |
| `.清空` | — | 全删掉 |

下标从 0 开始。`删除` 会把删掉的那个还给你，所以"取出并删除"一步就能写完：

```简言
私有 整数 第一个 = 分数.删除(0)
```

## 7.4 遍历组

```简言
对 x 在 分数 {
    打印(x)
}
```

要下标就自己数：

```简言
私有 整数 i = 0
当 i << #分数 就 {
    打印(分数[i])
    i = i + 1
}
```

`对` 遍历时**不要往组里追加或删除元素**。这一版没做迭代器失效检查，
长度一变，循环就会跑到你没想到的地方。

## 7.5 映射

```简言
私有 映射[字符串, 整数] 库存 = {"苹果": 12, "香蕉": 7}
```

类型是 `映射[键类型, 值类型]`。字面量是 `{键: 值, ...}`。

| 方法 | 返回 | 说明 |
|---|---|---|
| `.取(k)` | `可空[V]` | 没有这个键给 `空` |
| `.插入(k, v)` | `可空[V]` | 返回被顶掉的旧值 |
| `.删除(k)` | `可空[V]` | 返回被删的值 |
| `.包含(k)` | `布尔值` | |
| `.键组` | `K 组` | 所有键 |
| `.值组` | `V 组` | 所有值 |
| `.大小` | `整数` | 有几对 |
| `.清空` | — | |

映射**没有顺序保证**。要按顺序输出，先把键排序：

```简言
私有 字符串 组 键 = 库存.键组()
键.排序()
对 k 在 键 {
    打印(k) 打印("=") 打印行(库存.取(k).取值)
}
```

（上面的例子没排序，所以输出顺序是 `苹果 香蕉 橙子`——这一版恰好按插入顺序，
但别指望它。）

## 7.6 为什么 `取` 返回可空

```简言
库存.取("西瓜")          -- 可空[整数]，可能是 空
库存.取("西瓜").取值      -- 空的时候直接崩
库存.取("西瓜").或默认(0) -- 空的给 0
```

如果 `取` 直接返回值，就只有两条路：崩，或者返回一个假的 0。前者太狠，后者
会让你把"没有"当成"数量是 0"。返回 `可空` 把这件事摆到台面上，你必须选一种处理方式。

`如果 库存.取("西瓜") != 空 就 { ... }` 之后，块里可以直接 `.取值`，
编译器知道这里已经确认有值了。

## 7.7 嵌套

```简言
私有 映射[字符串, 整数 组] 班级 = {}

私有 整数 组 甲班 = {90, 85}
班级.插入("一班", 甲班)

私有 可空[整数 组] 拿到 = 班级.取("一班")
如果 拿到 != 空 就 {
    打印行(#拿到.取值)
}
```

注意 `班级.取("一班")` 拿到的是"组的可空"，要 `.取值` 之后才是组，再 `#` 才是长度。
不要写 `#班级.取("一班").取值`——`.取值` 的优先级和成员访问混在一起容易读错，分开写。

## 7.8 小结

| 想干什么 | 写法 |
|---|---|
| 声明组 | `整数 组 名 = {1, 2, 3}` |
| 声明映射 | `映射[字符串, 整数] 名 = {"a": 1}` |
| 长度 | `#组`、`映射.大小` |
| 添加 | `.追加(x)`、`.插入(k, v)` |
| 安全取值 | `.取(i)` → 可空 |
| 遍历 | `对 x 在 组`、`对 k 在 映射.键组()` |
