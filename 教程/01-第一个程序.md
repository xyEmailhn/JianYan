# 第 1 章 · 第一个程序

> 一个简言程序由三样东西组成：模块名、函数、语句。先把最小的那一个写对。

## 1.1 完整代码

文件 `教程/例子/01-你好.jy`：

```简言
-- 第一章：最小的程序。
-- `模块` 声明这个名字（只能写一次），`主` 是入口，返回值就是退出码。
模块 教程.你好

函数 主() -> 整数 {
    打印行("你好，简言")
    打印("1 + 2 = ")
    打印行(1 + 2)
    返回 0
}
```

输出：

```
你好，简言
1 + 2 = 3
```

## 1.2 一行一行拆

### `模块 教程.你好`

- 一个文件一个模块，`模块` 只能出现一次，而且必须在最前面（注释可以写在它前面）。
- 名字用点分层：`教程.你好` 表示"教程"这个大类下的"你好"。
- **模块名不能用关键字。** 写 `模块 教程.类型` 会被拒绝，因为 `类型` 是保留字。
  这条踩过好几次，报错长这样：
  ```
  语法错误：这里需要一个名字（点号后面要跟名字），但 `类型` 是语言保留的关键字
  ```

### `函数 主() -> 整数`

- `主` 是入口，必须有，返回 `整数`——这个整数就是进程退出码，`0` 表示成功。
- `->` 后面是返回类型。没有返回值就不写 `->`。
- 函数体必须用 `{}` 包住，**没有分号**，一行一句。

### `打印行(...)` 和 `打印(...)`

| 函数 | 行为 |
|---|---|
| `打印行(x)` | 打印 x，再换行 |
| `打印(x)` | 只打印，不换行 |

两者都接受任意类型，数字会按十进制、浮点按 `%g` 风格、布尔打成 `真`/`假`。

```简言
打印("一共 ")
打印(3)
打印(" 个")
打印行("")
```

输出 `一共 3 个`。想拼成一整行，也可以用 `..` 拼字符串，但**两边必须都是字符串**：

```简言
打印行("一共 " .. 字符串(3) .. " 个")
```

### 注释

```简言
-- 单行注释
--[[
   多行注释
]]
```

注释用两个减号，和 SQL 一样。因为 `//` 已经被"整除"占用了。

## 1.3 为什么入口叫 `主` 不叫 `main`

因为关键字、内置函数、标准库全是中文的。规则很统一：**你能看见的名字都是中文**，
只有运算符和标点是半角符号。学了这一条，后面所有名字都不用猜。

## 1.4 常见的第一天错误

| 你写的 | 报错 | 原因 |
|---|---|---|
| `函数 主() -> 整数 { 打印行("hi") }` | 提示"不是所有路都会返回" | 少了 `返回 0`。有返回类型就必须每条路都返回 |
| `打印行("hi");` | 语法错误，实际是 `;` | 简言没有分号 |
| `模块 你好` 写在函数后面 | 语法错误 | `模块` 必须在最前 |
| `打印行（"hi"）` | 语法错误 | 用了全角括号 |

最后一条值得单独说：**全角符号一律不认**。中文输入法很容易打出全角的 `（）`、`，`、`"`，
报错位置会指向一个看起来很正常的字符。看到"这里应该写 `(`"却明明有括号，先检查全半角。

## 1.5 小结

| 概念 | 写法 |
|---|---|
| 模块声明 | `模块 名字`，文件开头，一次 |
| 入口 | `函数 主() -> 整数 { ... 返回 0 }` |
| 打印 | `打印(x)` / `打印行(x)` |
| 注释 | `--` 或 `--[[ ]]` |
| 分号 | 没有 |
| 符号 | 全半角 |
