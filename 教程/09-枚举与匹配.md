# 第 9 章 · 枚举与匹配

> 枚举不是"几个常量换名字"，它能给每个变体带上不同的数据。
> 配合 `匹配`，一条分支处理一种情况，漏一种编译器就报错。

## 9.1 完整代码

`教程/例子/09-枚举.jy`：

```简言
模块 教程.形状

枚举 形状 {
    圆(半径: 浮点)
    矩形(宽: 浮点, 高: 浮点)
    点
}

函数 面积(s: 借用 形状) -> 浮点 {
    匹配 s {
        例 形状.圆(半径): { 返回 3.14159 * 半径 * 半径 }
        例 形状.矩形(宽, 高): { 返回 宽 * 高 }
        例 形状.点: { 返回 0.0 }
    }
}

函数 描述(s: 借用 形状) -> 字符串 {
    匹配 s {
        例 形状.圆(半径): { 返回 "圆 r=" .. 字符串(半径) }
        例 形状.矩形(宽, 高): { 返回 "矩形 " .. 字符串(宽) .. "×" .. 字符串(高) }
        例 形状.点: { 返回 "一个点" }
    }
}

函数 主() -> 整数 {
    私有 形状 甲 = 形状.圆(2.0)
    私有 形状 乙 = 形状.矩形(3.0, 4.0)
    私有 形状 丙 = 形状.点

    打印行(描述(借用 甲))
    打印("面积 ") 打印行(面积(借用 甲))

    打印行(描述(借用 乙))
    打印("面积 ") 打印行(面积(借用 乙))

    打印行(描述(借用 丙))
    打印("面积 ") 打印行(面积(借用 丙))
    返回 0
}
```

```
圆 r=2
面积 12.5664
矩形 3×4
面积 12
一个点
面积 0
```

## 9.2 声明

```简言
枚举 形状 {
    圆(半径: 浮点)
    矩形(宽: 浮点, 高: 浮点)
    点
}
```

| 部分 | 说明 |
|---|---|
| 变体名 | 大写开头更常见，但语言不强制 |
| 带数据的变体 | `名字(字段: 类型, ...)`，字段类型写全 |
| 不带数据的变体 | 光写名字 |
| 一行一个 | 同结构，不写逗号 |

**同一个枚举里各变体的数据可以完全不同。** 这是它比"一堆整数常量"强的地方：
`圆` 有一个半径，`矩形` 有两个，`点` 什么都没有，但在类型系统里它们都是 `形状`。

## 9.3 构造

```简言
私有 形状 甲 = 形状.圆(2.0)
私有 形状 乙 = 形状.矩形(3.0, 4.0)
私有 形状 丙 = 形状.点
```

带数据的变体像函数调用，不带数据的变体就是一个值。**前缀 `形状.` 不能省**，
省了会报"找不到 `圆`"。

如果有一个变体实在没法穷尽（比如以后还会加），可以用 `默认` 兜底：

```简言
匹配 s {
    例 形状.圆(半径): { 返回 半径 }
    默认: { 返回 0.0 }
}
```

加了 `默认` 就等于放弃穷尽检查——以后新增变体会静悄悄落进 `默认`。
除非真有必要，宁可写全。

## 9.4 匹配

```简言
匹配 s {
    例 形状.圆(半径): { ... }
    例 形状.矩形(宽, 高): { ... }
    例 形状.点: { ... }
}
```

三条规则：

1. **必须写全**。漏掉一个变体会报错：`匹配 没有处理 点，也没写 默认。枚举必须穷尽`。
2. **括号里是绑定**。`圆(半径)` 把这个变体带的那个值绑到局部变量 `半径` 上，
   块里直接用。不想要名字可以写 `_`。
3. **每个 `例` 冒号后面必须跟着 `{}`**，哪怕只有一句。

`匹配` 是语句，不是表达式：它不"返回"值。要在分支里给结果，就在分支里 `返回`，
或者给外层变量赋值：

```简言
私有 浮点 结果 = 0.0
匹配 s {
    例 形状.圆(半径): { 结果 = 3.14159 * 半径 * 半径 }
    例 形状.矩形(宽, 高): { 结果 = 宽 * 高 }
    例 形状.点: { 结果 = 0.0 }
}
```

## 9.5 为什么不用 if 判断

```简言
-- 不推荐：类型关系埋在条件里，加一个变体就要改三处
如果 是圆(s) 就 { ... } 否则 如果 是矩形(s) 就 { ... }

-- 推荐：一处列全，漏了编译器提醒
匹配 s {
    例 形状.圆(半径): { ... }
    例 形状.矩形(宽, 高): { ... }
    例 形状.点: { ... }
}
```

真正的好处是**加变体的时候**。三个月后你给 `形状` 加了个 `三角形`，
所有 `匹配` 它的地方会立刻编译失败，一处一处补。如果是 `if` 链，漏掉的地方
会安静地走 `否则` 分支，错在运行时。

## 9.6 借用还是复制

枚举通常比机器字大（要装下最大的那个变体），所以传参一般写 `借用`：

```简言
函数 面积(s: 借用 形状) -> 浮点
```

`匹配 s` 时 `s` 是借来的，绑定出来的 `半径`、`宽` 也都是借来的视图，
只读没问题。要拿走里面的数据（比如把 `圆` 的半径取出来存起来），
就把它赋给一个新变量，语义层会提示你该怎么写。

## 9.7 这一版的限制

`匹配` 目前只支持**枚举变体**这一种模式。规范里的字面量和范围分支
（`例 0:`、`例 1~9:`）还没接，写了会得到一条 C 编译错误。用整数分情况时，
这一版请写 `如果 ... 否则如果 ...`。

## 9.8 小结

| 想干什么 | 写法 |
|---|---|
| 定义 | `枚举 名 { 变体(字段: 类型) ... }` |
| 构造 | `名.变体(值, ...)` |
| 分情况 | `匹配 x { 例 名.变体(绑定): { } }` |
| 兜底 | 枚举不需要兜底——写全就行 |
| 穷尽检查 | 编译器自动做 |
