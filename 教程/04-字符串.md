# 第 4 章 · 字符串

> 字符串不可变，所有"改"都返回新串。长度按字符算，不按字节。数字和字符串不能直接相加。

## 4.1 完整代码

`教程/例子/04-字符串.jy`：

```简言
模块 教程.文本

函数 主() -> 整数 {
    私有 字符串 s = "  Hello, 简言  "
    打印("[") 打印(s) 打印行("]")

    打印("长度 ") 打印行(#s)
    打印("去空白后 [") 打印(s.去空白()) 打印行("]")
    打印("大写 ") 打印行(s.去空白().大写())
    打印("全小写 ") 打印行(s.去空白().大写().小写())

    私有 可空[整数] 位 = s.查找("简言")
    如果 位 != 空 就 {
        打印("简言在第 ") 打印(位.取值()) 打印行(" 个字符")
    }

    私有 字符串 组 段 = s.去空白().切分(",")
    打印("切成 ") 打印(#段) 打印行(" 段")
    打印("第二段 [") 打印(段[1]) 打印行("]")

    打印("替换 ") 打印行(s.去空白().替换("Hello", "你好"))
    打印("开头是空格 ") 打印行(s.开头是("  "))
    打印("包含逗号 ") 打印行(s.包含(","))

    私有 字符串 拼 = "共 " .. 字符串(#段) .. " 段"
    打印行(拼)
    私有 结果[整数, 字符串] r = "2024".转整数()
    如果 r.是成功 就 { 打印("转成整数 ") 打印行(r.取值) }
    返回 0
}
```

## 4.2 长度、拼接、取字符

```简言
#s              -- 字符数：中文一个字算 1
s.长度           -- 同上
s.字节长度       -- UTF-8 字节数：一个汉字 3
s .. t          -- 拼接，两边必须都是字符串
s[i]            -- 第 i 个字符（单字符串），越界直接崩
s.取(i)         -- 安全版，返回 可空[字符串]
```

`#s` 对 `"杭州"` 给 2，`.字节长度` 给 6。**用哪个取决于你在数什么**：
排版、截断、光标位置要字符数；算字节、算文件大小要字节长度。

## 4.3 数字与字符串不能直接拼

```简言
打印行("共 " .. 3 .. " 人")          -- 编译错误
打印行("共 " .. 字符串(3) .. " 人")  -- 对
```

C 会悄悄把它变成指针运算，Python 会悄悄调 `str()`，JavaScript 会拼出 `"共 3 人"` 也可能
拼出别的东西。简言三个都不学：**要拼就自己转**。一行里出现三次 `字符串(...)` 是有点啰嗦，
但再也不会出现"这里到底是加法还是拼接"的疑问。

## 4.4 全部方法

| 方法 | 返回 | 说明 |
|---|---|---|
| `.长度` | `整数` | 字符数，同 `#s` |
| `.字节长度` | `整数` | UTF-8 字节数 |
| `.取(i)` | `可空[字符串]` | 越界给 `空` |
| `.包含(子)` | `布尔值` | |
| `.查找(子)` | `可空[整数]` | 第几个**字符**，不是字节 |
| `.切分(分隔符)` | `字符串 组` | |
| `.替换(旧, 新)` | `字符串` | 全部替换 |
| `.大写` / `.小写` | `字符串` | 只处理 ASCII，中文原样 |
| `.去空白` | `字符串` | 去掉两头的空格、换行、制表符 |
| `.开头是(子)` / `.结尾是(子)` | `布尔值` | |
| `.转整数` | `结果[整数, 字符串]` | 失败带原因 |
| `.转浮点` | `结果[浮点, 字符串]` | 失败带原因 |

没有 `.子串`。要中间一段，用 `切分` 或 `取`：

```简言
私有 字符串 日期 = "2026-11-22"
私有 字符串 组 段 = 日期.切分("-")
打印行(段[0])   -- 2026
打印行(段[1])   -- 11
```

## 4.5 链式调用

方法返回字符串，所以可以一路点下去：

```简言
打印行(s.去空白().大写().小写().替换("HELLO", "Hi"))
```

读的顺序是从左到右，先做左边的。整条链里只要有一环返回的不是字符串，后面就编不过——
编译器会直接指出来，不会让你在运行时才发现。

## 4.6 两个坑

**一、字符串不可变。** `s.大写()` 不会改 `s`，它返回一个新串：

```简言
s.大写()          -- 这行的结果被丢掉了，s 一点没变
私有 字符串 t = s.大写()   -- 这样才有用
```

**二、`查找` 返回字符下标，不是字节下标。** `"你好，简言"` 里 `"简言"` 的下标是 3，
不是 6 或 9。如果你要拿它去切字节数组，记得先换算。

## 4.7 小结

| 想干什么 | 写法 |
|---|---|
| 长度 | `#s` 或 `s.长度` |
| 拼接 | `a .. b`，两边都得是字符串 |
| 数字转文字 | `字符串(x)` |
| 文字转数字 | `s.转整数()`，返回结果 |
| 切分 | `s.切分(",")` |
| 去空白 | `s.去空白()` |
