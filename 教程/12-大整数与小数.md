# 第 12 章 · 大整数与小数

> `整数` 是 64 位，超过就绕回去；`浮点` 是二进制，`0.1` 存不准。
> 要"位数不限"用 `大整数`，要"十进制意义上准确"用 `小数`。

## 12.1 完整代码

`教程/例子/12-大数.jy`：

## 12.2 为什么需要大整数

`整数` 是 64 位，最大 `9223372036854775807`。阶乘长到 21 就超了：

```
20! = 2432902008176640000        -- 装得下
21! = 51090942171709440000       -- 装不下，绕回去了
```

`大整数` 没有这个限制。它是任意精度，代价是每次运算都要分配内存。

```简言
私有 大整数 a = 大数(1)
私有 大整数 b = a.乘(大数(100))       -- 返回新值，a 不变
打印行(b.文本())
```

## 12.3 大整数的方法

| 方法 | 返回 | 说明 |
|---|---|---|
| `大数(整数)` | `大整数` | 从整数构造 |
| `读大数(字符串)` | `结果[大整数, 字符串]` | 十进制，也认 `0x` `0b` `0o`、正负号、前后空格 |
| `.加` `.减` `.乘` `.除` `.余` | `大整数` | 都返回新值 |
| `.幂(n)` | `大整数` | n 次方，n 为负或超过一千万给 0 |
| `.根` | `大整数` | 整数平方根，向下取整 |
| `.比(别的)` | `整数` | 小于 -1，等于 0，大于 1 |
| `.位` | `整数` | 十进制有几位 |
| `.文本` | `字符串` | 十进制文字 |

**全部不可变。** `a.乘(b)` 不改 `a`，它返回一个新的 `大整数`。所以：

```简言
果 = 果.乘(大数(i))       -- 要接住返回值
果.乘(大数(i))            -- 这行的结果被丢掉了，果 没变
```

这也带来一个好处：**传参不用写 `借用`**。既然没人能改它，复制指针就永远安全。

## 12.4 为什么需要小数

浮点是二进制，`0.1` 在二进制里是无限循环小数，只能存一个近似值：

```简言
打印行(0.1 + 0.2 == 0.3)     -- 假
```

`小数` 是十进制浮点。`读小数("0.1")` 拿到的是精确的 0.1：

```简言
私有 小数 甲 = 读小数("0.1").取值
私有 小数 乙 = 读小数("0.2").取值
打印行(甲.加(乙).文本())                      -- 0.3
打印行(甲.加(乙).比(读小数("0.3").取值))       -- 0
```

## 12.5 小数的方法与精度

| 方法 | 说明 |
|---|---|
| `读小数(字符串)` | 精确读取，返回结果 |
| `变小数(浮点)` | 把一个 double 的十进制真值摊开（`0.1` 会变成 `0.10000000000000001`） |
| `.加` `.减` `.乘` `.除` | 按当前精度舍入 |
| `.比(别的)` | -1 / 0 / 1 |
| `.文本` | 定点写法，不用科学计数法 |
| `定小数精度(n)` | 设有效位数，**作用于下一次运算** |
| `小数精度()` | 当前有效位数，默认 34 |

精度是"有效数字位数"，不是"小数点后几位"：

```简言
定小数精度(50)
打印行(变小数(1.0).除(读小数("3").取值).文本())
-- 0.33333333333333333333333333333333333333333333333333
```

一个整数位 + 49 位小数，凑够 50 位有效数字。

`变小数(浮点)` 值得单独记一笔：它不会"猜你想要什么"，而是把 double 里**真实存着**的
十进制展开：

```简言
打印行(变小数(0.1).文本())    -- 0.10000000000000001
```

这是 double 的实话。要 0.1 就说 `读小数("0.1")`。

## 12.6 选哪个

| 场景 | 用 |
|---|---|
| 计数、下标、位运算 | `整数` |
| 物理量、图形坐标、科学计算 | `浮点` |
| 金额、账单、需要精确十进制 | `小数` |
| 阶乘、大素数、密码学 | `大整数` |

金额用 `浮点` 是个经典错误：`0.1 + 0.2` 不等于 `0.3`，对到分上就会差一分钱。
简言把 `小数` 做进语言，就是为了让这件事有个现成的答案。

## 12.7 小结

| 想干什么 | 写法 |
|---|---|
| 造大整数 | `大数(整数)` 或 `读大数("...")` |
| 大整数运算 | `a.加(b)`、`a.乘(b)`、`a.幂(1000)` |
| 造小数 | `读小数("0.1")` 或 `变小数(1.0)` |
| 小数运算 | `a.加(b)`、`a.除(b)` |
| 设精度 | `定小数精度(50)` |
| 变文字 | `.文本` |
