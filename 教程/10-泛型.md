# 第 10 章 · 泛型

> 泛型就是"类型先空着，用的时候填"。简言的实现方式是单态化：每个具体类型
> 各生成一份代码，运行时没有任何额外开销——但代价是二进制会变大。

## 10.1 完整代码

`教程/例子/10-泛型.jy`：

```简言
模块 教程.通用

函数 最大[T: 可比较](甲: T, 乙: T) -> T {
    如果 甲 >> 乙 就 { 返回 甲 }
    返回 乙
}

函数 三个最大[T: 可比较](甲: T, 乙: T, 丙: T) -> T {
    返回 最大(最大(甲, 乙), 丙)
}

函数 总和[T](xs: 借用 T 组) -> T {
    私有 T 和 = xs[0]
    私有 整数 i = 1
    当 i << #xs 就 {
        和 = 和 + xs[i]
        i = i + 1
    }
    返回 和
}

函数 主() -> 整数 {
    打印("最大(3, 9) = ") 打印行(最大(3, 9))
    打印("最大(1.5, 2.5) = ") 打印行(最大(1.5, 2.5))
    打印("最大(\"abc\", \"abd\") = ") 打印行(最大("abc", "abd"))
    打印("三个最大(7, 2, 5) = ") 打印行(三个最大(7, 2, 5))

    私有 整数 组 整数们 = {1, 2, 3, 4}
    私有 浮点 组 浮点们 = {0.5, 1.5, 2.0}
    打印("整数总和 ") 打印行(总和(借用 整数们))
    打印("浮点总和 ") 打印行(总和(借用 浮点们))
    返回 0
}
```

```
最大(3, 9) = 9
最大(1.5, 2.5) = 2.5
最大("abc", "abd") = abd
三个最大(7, 2, 5) = 7
整数总和 10
浮点总和 4
```

## 10.2 语法

```简言
函数 名字[T](x: T) -> T              -- 无约束
函数 名字[T: 可比较](甲: T, 乙: T)    -- 约束：T 要能比大小
```

| 部分 | 说明 |
|---|---|
| `[T]` | 类型参数，习惯用大写单字母 |
| `[T: 可比较]` | 约束，说明这个函数里会对 T 用 `>>`、`<<` |
| 多个参数 | `[T, U]`，逗号分隔 |

约束只是"承诺"，这一版不做严格校验：写了 `[T: 可比较]` 但函数体里没比大小也能过；
反过来，没写约束却在函数体里比大小，也能过（单态化到具体类型时才真正检查）。
写上是好习惯——它是给人看的文档。

## 10.3 一份代码，多份产物

```简言
最大(3, 9)          -- 生成 最大$整数
最大(1.5, 2.5)      -- 生成 最大$浮点
最大("abc", "abd")  -- 生成 最大$字符串
```

三个调用，编译器生成三份独立的机器码。好处是**运行时没有类型判断**——
调用 `最大$整数` 就是一条 `cmp` 加两条 `jcc`，和手写的没区别。
代价是代码体积随用到的类型数线性增长。

这就是"单态化"。C++ 的模板、Rust 的泛型都是这个路子。Java 的擦除和 Go 早期的
字典方案走的是另一条路：运行时查表，代码只有一份，但每次调用多一层间接。

## 10.4 泛型也能用在容器上

```简言
函数 总和[T](xs: 借用 T 组) -> T {
    私有 T 和 = xs[0]
    私有 整数 i = 1
    当 i << #xs 就 {
        和 = 和 + xs[i]
        i = i + 1
    }
    返回 和
}
```

`T 组` 就是"元素是 T 的组"。传 `整数 组` 生成一份，传 `浮点 组` 再生成一份。

注意这个函数用了 `+`，所以它只对"能相加"的类型成立。字符串不行（拼接要写 `..`），
结构也不行（没定义加法）。想要更通用的"归约"，就得把操作也传进来——这一版
函数值还不能当参数调用，所以先这样。

## 10.5 什么时候用泛型

| 场景 | 用不用 |
|---|---|
| 逻辑和类型无关，只是"装东西、比大小、遍历" | 用 |
| 只有一两种类型会用 | 不用，直接写两个函数更清楚 |
| 需要在里面调用类型特有的方法 | 不用，泛型表达不了 |

一个实用的判断：**如果函数体里出现了只属于某个类型的方法名，那它就不该是泛型的。**

## 10.6 小结

| 想干什么 | 写法 |
|---|---|
| 泛型函数 | `函数 名[T](x: T) -> T` |
| 加约束 | `[T: 可比较]` |
| 泛型容器参数 | `借用 T 组` |
| 实现方式 | 单态化：一个类型一份代码，零运行时开销 |
