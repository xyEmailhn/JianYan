# 第 8 章 · 结构与方法

> 结构是"几个字段捆在一起"，方法是"挂在结构上的函数"。方法体里直接写字段名，
> 不用写 `自身.`——这是简言比别的语言省事的一处。

## 8.1 完整代码

`教程/例子/08-结构.jy`：

```简言
模块 教程.账户

结构 账户 {
    户名: 字符串
    余额: 整数
}

接口 可存取 {
    函数 存(n: 整数)
    函数 取(n: 整数) -> 布尔值
    函数 余额文本() -> 字符串
}

实现 账户 为 可存取 {
    函数 存(n: 整数) {
        余额 = 余额 + n
    }

    函数 取(n: 整数) -> 布尔值 {
        如果 n >> 余额 就 { 返回 假 }
        余额 = 余额 - n
        返回 真
    }

    函数 余额文本() -> 字符串 {
        返回 户名 .. " 有 " .. 字符串(余额) .. " 元"
    }
}

函数 主() -> 整数 {
    私有 账户 a = { "张三", 100 }
    打印行(a.余额文本())

    a.存(50)
    打印行(a.余额文本())

    打印("取 200 成功？") 打印行(a.取(200))
    打印("取 30 成功？")  打印行(a.取(30))
    打印行(a.余额文本())

    私有 账户 b = 新建 账户{ 户名: "李四", 余额: 0 }
    打印行(b.余额文本())
    返回 0
}
```

```
张三 有 100 元
张三 有 150 元
取 200 成功？假
取 30 成功？真
张三 有 120 元
李四 有 0 元
```

## 8.2 声明结构

```简言
结构 账户 {
    户名: 字符串
    余额: 整数
}
```

**字段一行一个，不写逗号。** 写 `{ 户名: 字符串, 余额: 整数 }` 会报
"这里需要一个名字（字段名），实际是 `,`"。这是为了让字段定义和变量声明长得一样。

字段类型必须写。字段可以是任何类型，包括别的结构、组、映射：

```简言
结构 矩形 {
    左下: 点
    右上: 点
}
```

## 8.3 构造

三种写法，按场景选：

```简言
私有 账户 a = { "张三", 100 }                    -- 按字段顺序
私有 账户 b = 新建 账户{ "张三", 100 }            -- 显式类型名 + 顺序
私有 账户 c = 新建 账户{ 余额: 100, 户名: "张三" } -- 写字段名，顺序随便
```

| 场景 | 推荐写法 |
|---|---|
| 声明的同时初始化 | `账户 a = { ... }`（靠左边类型推断） |
| 当表达式用：`返回`、实参、组元素 | `新建 账户{ ... }` |
| 字段多或容易混 | `新建 账户{ 字段: 值, ... }` |

**在表达式位置一定要写 `新建`。** 裸写 `账户{ ... }` 会被当成"名字 + 代码块"，
因为花括号在简言里有两个身份。这是硬规则，不是风格建议。

没写的字段自动清零（`0`、`""`、`假`、`空`）。

## 8.4 方法与"看不见的自身"

方法写在 `实现 类型 为 接口 { ... }` 块里：

```简言
实现 账户 为 可存取 {
    函数 存(n: 整数) {
        余额 = 余额 + n       -- 余额 就是 自身.余额
    }
}
```

三件事值得说清楚：

**一、接口要先声明。** `接口 可存取 { 函数 存(n: 整数) ... }` 只写签名，
不写函数体。`实现 账户 为 可存取` 表示"账户 满足 可存取"。

**二、方法体里字段就是普通变量。** 编译器给每个方法偷偷加了第 0 个参数 `自身`，
类型是结构本身；`余额` 被改写成 `自身.余额`。所以你在方法里写 `余额 = 余额 + n`
就等于改这个对象。

**三、改字段的方法，自身自动是 `可变借用`。** 不用手写。上例的 `存` 改了 `余额`，
编译器就把 `自身` 定为可变借用，调用 `a.存(50)` 改的真是 `a`。

只有读的方法，`自身` 就是普通借用：

```简言
函数 余额文本() -> 字符串 {
    返回 户名 .. " 有 " .. 字符串(余额) .. " 元"
}
```

## 8.5 调用

```简言
打印行(a.余额文本())
a.存(50)
如果 a.取(30) 就 { ... }
```

调用时对象自动当第一个实参传，你只写自己声明的那些参数。

**方法不会自动链式返回自身。** `a.存(50)` 没有返回值（返回类型是空），
所以不能写 `a.存(50).存(20)`。要连续调用就分两行。

## 8.6 什么时候该用结构

| 信号 | 说明 |
|---|---|
| 三个以上值总是一起出现 | `x, y, w, h` 到处传，该合成一个 `矩形` |
| 函数返回多个值 | 用结构包，别用全局变量 |
| 有一组操作只对某类数据有意义 | 把数据和方法放一起 |

反过来说，**两个字段的小东西不必都做成结构**。`点` 有 `x` `y` 是值得的，
`一对整数` 通常不值得。

## 8.7 常见错误

| 现象 | 原因 |
|---|---|
| `这里需要一个名字（字段名），实际是 ,` | 字段之间加了逗号 |
| `这里需要一个表达式，实际是 自身` | 这一版 `自身` 还不能当表达式用，方法里直接写字段名 |
| `找不到接口 形状` | `实现` 写在 `接口` 前面了，接口必须先声明 |
| `后端还没实现方法：xxx` | 方法名拼错，或者调了一个没在 `实现` 块里定义的方法 |

## 8.8 小结

| 想干什么 | 写法 |
|---|---|
| 定义 | `结构 名 { 字段: 类型 ... }`（一行一个） |
| 构造 | `名{ 值, 值 }` 或 `新建 名{ 字段: 值 }` |
| 声明能力 | `接口 名 { 函数 签名 }` |
| 实现方法 | `实现 类型 为 接口 { 函数 ... }` |
| 方法里访问字段 | 直接写字段名 |
| 调用 | `对象.方法(实参)` |
