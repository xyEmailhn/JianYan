# 第 13 章 · 图与声音

> 这两个类型是**句柄**：`私有 图 乙 = 甲` 不复制像素，只多一个名字指向同一张图。
> 想在语言里直接画图、合成音频，就靠它们。

## 13.1 完整代码

`教程/例子/13-图与声音.jy`：

```简言
模块 教程.媒体

函数 色(r: 整数, g: 整数, b: 整数) -> 整数 {
    返回 r * 16777216 + g * 65536 + b * 256 + 255
}

函数 主() -> 整数 {
    -- ---- 图 ----
    私有 图 画布 = 新建图(64, 32)

        画布.设(i, i // 2, 色(255, 80, 40))

    打印("(0,0) 的颜色 ") 打印行(画布.取(0, 0))
    打印("越界取 ") 打印行(画布.取(999, 999))

    如果 存图.是成功 就 { 打印行("已存到 /tmp/教程-画布.png") }

    -- ---- 声音 ----

    打印("采样率 ") 打印行(波.采样率)
```

## 13.2 图

```简言
私有 图 画布 = 新建图(64, 32)     -- 宽 64，高 32，透明黑
```

| 成员 | 签名 | 说明 |
|---|---|---|
| `.宽` `.高` | `整数` | 像素尺寸 |
| `.取(x, y)` | `整数` | 颜色，打包成 `0xRRGGBBAA`；越界给 0 |
| `.设(x, y, 色)` | — | 写一个像素；越界静默忽略 |
| `.缩放(宽, 高)` | `图` | 双线性，返回**新图** |
| `读图(路径)` | `结果[图, 字符串]` | 读 PNG/JPG/BMP/TGA/GIF/PSD/HDR，以及 SVG |
| `.存(路径)` | `结果[空值, 字符串]` | 按扩展名选 png/jpg/bmp/tga |
| `.写字(x, y, 字号, 文字, 色)` | `整数` | 返回写了几个字；`-1` 表示没找到字体 |
| `.量字(文字, 字号)` | `浮点` | 这行字有多宽，排版用 |

颜色没有单独的类型，就是一个整数 `0xRRGGBBAA`：

```简言
函数 色(r: 整数, g: 整数, b: 整数) -> 整数 {
    返回 r * 16777216 + g * 65536 + b * 256 + 255
}
```

为什么不给颜色单独做个类型？因为加一个类型要改词法、语义、后端三层，而
`0xRRGGBBAA` 和图 `.取` 的返回值天然对得上，插值函数两行就能写：

```简言
函数 混(甲: 整数, 乙: 整数, t: 浮点) -> 整数 {
    私有 整数 r = 整数(浮点((甲 // 16777216) % 256) * (1.0 - t) + 浮点((乙 // 16777216) % 256) * t)
    私有 整数 g = 整数(浮点((甲 // 65536) % 256) * (1.0 - t) + 浮点((乙 // 65536) % 256) * t)
    私有 整数 b = 整数(浮点((甲 // 256) % 256) * (1.0 - t) + 浮点((乙 // 256) % 256) * t)
    返回 色(r, g, b)
}
```

坐标原点在**左上角**，`y` 向下增大。

存了还能读回来，像素值原样保留：

```简言
私有 结果[图, 字符串] 读回 = 读图("/tmp/教程-画布.png")
如果 读回.是成功 就 {
    打印("读回来的尺寸 ") 打印(读回.取值.宽) 打印("×") 打印行(读回.取值.高)
}
```

## 13.3 声音

```简言
私有 声音 波 = 新建声音(帧数, 采样率, 声道)
```

单位是**帧**：一帧包含所有声道在同一时刻的采样。8000 Hz 单声道 0.5 秒就是
`8000 * 0.5 = 4000` 帧。

| 成员 | 签名 | 说明 |
|---|---|---|
| `.帧数` `.采样率` `.声道` | `整数` | |
| `.时长` | `浮点` | 帧数 / 采样率 |
| `.取(帧, 声道)` | `浮点` | 越界给 0.0 |
| `.设(帧, 声道, 值)` | — | 写入 |
| `.混(帧, 声道, 值)` | — | **累加**，合成和弦用 |
| `.放大(倍数)` | `声音` | 整条乘倍数，返回新声音 |
| `.归一化` | `声音` | 峰值拉到 0.98，返回新声音 |
| `.存(路径)` | `结果[空值, 字符串]` | 16 位 PCM WAV |

合成一个音：

```简言
私有 整数 帧 = 0
当 帧 << 波.帧数 就 {
    私有 浮点 t = 浮点(帧) / 浮点(波.采样率)
    波.设(帧, 0, 0.6 * 正弦(2.0 * 3.14159265 * 440.0 * t))
    帧 = 帧 + 1
}
```

`t` 是秒，`440.0 * t` 是"已经过了多少个周期"，乘 `2π` 再取正弦就是波形。
采样率越高，同一个音越细腻；8000 Hz 够听出音高，44100 Hz 才是 CD 音质。

采样值名义范围 `[-1, 1]`，但**不钳位**。叠三路正弦超过 1 是常事，库里悄悄压扁
反而让你以为音量已经调好了。要控制在范围内就 `.归一化()`。

## 13.4 句柄语义：赋值不复制

```简言
私有 图 甲 = 新建图(100, 100)
私有 图 乙 = 甲          -- 不是复制！乙 和 甲 是同一张图
乙.设(0, 0, 色(255, 0, 0))
打印行(甲.取(0, 0))     -- 也变了
```

为什么这样设计？一张 1200×750 的图是 3.6 MB。如果每次赋值都拷一份，
写起来轻松、跑起来灾难。所以赋值和传参只搬那个 24 字节的句柄。

要独立副本就显式做，而且这个操作本来就要分配新内存：

```简言
私有 图 副本 = 甲.缩放(甲.宽, 甲.高)   -- 同尺寸缩放 = 复制
```

声音一样：`.放大(1.0)` 是最省事的"复制一份"。

## 13.5 这一版没有的

- **播放**。`.存` 只写文件，不发声。想听就用系统播放器打开生成的 wav。
- **MP3 解码**。`载入声音` 支持 WAV 与 MP3，但只在前面的示例流程里验过，
  教程里没展开。
- **字体**。`.写字` 找不到字体就返回 `-1`，不会崩——但也写不出字来。

## 13.6 小结

| 想干什么 | 写法 |
|---|---|
| 新建图 | `新建图(宽, 高)` |
| 画点 | `图.设(x, y, 0xRRGGBBAA)` |
| 读点 | `图.取(x, y)` |
| 存图 | `图.存("a.png")` |
| 新建声音 | `新建声音(帧数, 采样率, 声道)` |
| 写样本 | `声.设(帧, 声道, 值)` |
| 叠加 | `声.混(帧, 声道, 值)` |
| 存音频 | `声.存("a.wav")` |
