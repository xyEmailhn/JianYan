## 3.2 四则运算和三种"除法感"

| 写法 | 结果 | 说明 |
|---|---|---|
| `7 / 2` | `3.5` | **总是浮点**，哪怕两边都是整数 |
| `7 // 2` | `3` | 整除，向零截断（和 C 一致） |
| `-7 // 2` | `-3` | 是 -3 不是 -4，因为向零截断 |
| `7 % 3` | `1` | 余数，**符号跟着被除数** |
| `-7 % 3` | `-1` | |

`/` 的设计是有意的。C 里 `7/2` 得 3，Python 3 里得 3.5，两门语言的人互相看得一头雾水。
简言选了后者：**`/` 就是数学除法，要整除就明写 `//`**。语义层看到两个整数用 `/`
还会提示一句"想整除写 `//`"。

`%` 只能用于整数。浮点要取余得自己写 `甲 - 向下取整(甲 / 乙) * 乙`。

## 3.3 乘方

`^` 是乘方，不是异或（异或是 `^^`）。右结合，优先级高于一元负号：

```简言
打印行(2 ^ 10)    -- 1024
打印行(2 ^ 3 ^ 2) -- 2^(3^2) = 512，不是 (2^3)^2
打印行(-2 ^ 2)    -- -4，即 -(2^2)
打印行(9 ^ 0.5)   -- 3.0，指数可以是浮点
```

## 3.4 比较：尖尖朝里是"小于"

这是全语言最容易看错的一处：

| 写法 | 含义 |
|---|---|
| `a << b` | a 小于 b |
| `a >> b` | a 大于 b |
| `a <= b` | 小于等于 |
| `a >= b` | 大于等于 |
| `a == b` / `a != b` | 等于 / 不等于 |

为什么不用 `<` `>`？因为 `<<` `>>` 已经被"远小于/远大于"的视觉习惯占了，
干脆一双一对：**`<<` `>>` 是比较，`<<<` `>>>` 才是移位**。

```简言
打印行(3 << 5)    -- 真
打印行(3 <<< 5)   -- 24（3 左移 5 位）
```

## 3.5 逻辑：与、或、非，短路的

```简言
如果 年龄 >= 18 与 有证件 就 { ... }
如果 是周末 或 是节假日 就 { ... }
如果 非 找到 就 { ... }
```

- `与` `或` 只接受布尔值，**短路**：`与` 左边假就不看右边，`或` 左边真就不看右边。
- `非` 是一元，可以写 `非 x`，也可以写 `!x`。

短路不只是省事，它是写安全代码的基础：

```简言
如果 #组 >> 0 与 组[0] >> 10 就 { ... }   -- 前一半假，后一半根本不算，不会越界
```

## 3.6 位运算

| 运算 | 符号 | 例子 |
|---|---|---|
| 按位与 | `&` | `12 & 10 = 8` |
| 按位或 | `\|` | `12 \| 10 = 14` |
| 按位异或 | `^^` | `12 ^^ 10 = 6` |
| 按位取反 | `~~` | `~~0 = -1` |
| 左移 | `<<<` | `1 <<< 10 = 1024` |
| 右移 | `>>>` | `1024 >>> 10 = 1` |

只对整数有效。负数用补码，`~~0` 得 `-1` 就是这么来的。

## 3.7 优先级

从紧到松，记这张表就够了：

```
()  []  .           后缀
^                   乘方（右结合）
非 ! # ~~ - +       一元
*  /  //  %         乘除
+  -                加减
<<<  >>>            移位
<<  >>  <=  >=      比较
==  !=              相等
&                   按位与
^^                  按位异或
|                   按位或
与                  逻辑与
或                  逻辑或
..                  字符串拼接
=                   赋值（右结合）
```

拿不准就加括号。括号不要钱，读错一行代码要命。

## 3.8 内置数学函数

| 函数 | 签名 | 说明 |
|---|---|---|
| `开方(x)` | 浮点 → 浮点 | √x |
| `幂(a, b)` | 浮点 → 浮点 | a^b，等价于 `a ^ b` |
| `绝对值(x)` | 浮点 → 浮点 | 整数也可以，走的是 `.绝对值` 方法 |
| `最小(a,b)` / `最大(a,b)` | → 浮点 | |
| `向下取整` `向上取整` | 浮点 → 浮点 | |
| `四舍五入(x)` | 浮点 → **整数** | 和 `整数(x)` 的截断不一样 |
| `正弦` `余弦` `正切` | 弧度 → 浮点 | |
| `反正弦` `反余弦` `反正切` | → 浮点 | |
| `指数(x)` | 浮点 | e^x |
| `对数(x)` / `对数10(x)` | 浮点 | ln / log₁₀ |

角度用**弧度**。要算 30° 的正弦：`正弦(30.0 * 3.14159265 / 180.0)`。

## 3.9 浮点打印只有 6 位有效数字

`打印行(1.0 / 3.0)` 输出 `0.333333`。这是 `%g` 的默认精度，够看不够精。
要更多位数就用 `小数`（见[第 12 章](12-大整数与小数.md)），它是十进制精确运算。

## 3.10 小结

| 要点 | 记住这一句 |
|---|---|
| 除法 | `/` 给浮点，整除写 `//` |
| 取余 | `%` 只给整数，符号跟被除数 |
| 乘方 | `^`，右结合 |
| 比较 | `<<` 小于、`>>` 大于 |
| 移位 | `<<<`、`>>>` |
| 逻辑 | `与` `或` 短路，`非` 一元 |
