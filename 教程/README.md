# 简言教程

> 一本从零开始的简言入门书。每章配一个能跑的例子，例子在 `教程/例子/`，
> 运行结果在 `教程/期望/`。`bash 教程/跑.sh` 会把所有例子编一遍、跑一遍、
> 和期望输出逐字节比对——书里写的每个结果，都是机器验过的。

## 这是什么语言

简言是一门**中文关键字的编译型语言**。它想解决两件事：

1. 让没学过 C 的人也能读懂代码——关键字是中文，没有分号，块必须用 `{}` 包住；
2. 编出来的程序要快——直接生成机器码，不打包解释器，速度和 C 在一个量级。

```简言
模块 你好

函数 主() -> 整数 {
    打印行("你好，简言")
    返回 0
}
```

## 怎么开始

只需要 Linux（x86-64）、`gcc`、`make`、`as`、`ld`。源码里带了所有第三方库，
不需要联网。

```bash
cd 后端
make                 # 编出编译器 ./简编译，约 12 秒
./简编译 ../教程/例子/01-你好.jy -o /tmp/你好
/tmp/你好
```

## 建议的读法

- **完全新手**：从 00 顺读到 09，先把"能写出一个像样的小程序"这件事拿下。
- **会 C / Python**：直接跳到 [02](02-变量与类型.md) 看类型规则，
  再跳到 [14](14-编译与性能.md) 看它凭什么快，中间按需翻。
- **只想改编译器**：看 [14](14-编译与性能.md)，然后读 `规范/后端_v0.5_C参考后端.md`。

## 三个词先记住

| 词 | 意思 |
|---|---|
| **后端** | 把中间代码变成机器码的那一段。简言有两条：C 后端（经过 gcc）和原生后端（直接出汇编） |
| **句柄** | 赋值只搬一个"头"不复制内容。`图`、`声音` 是句柄，`字符串`、`组` 是值 |
| **不可变** | 改不了，任何"修改"都返回新值。`大整数`、`小数` 属于这一类 |

## 这一版没接的东西

教程只讲**真的能跑**的东西。v0.15 之后剩下的是这几样：匿名函数没有闭包、
`引入` 不支持别名和选择性引入、`匹配` 不能当表达式、没有 TLS/UDP、
没有共享内存的锁。遇到会明确报错，不会悄悄算错。第 [18](18-报错速查.md) 章有完整清单。
