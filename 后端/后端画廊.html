从 .jy 到机器码

前四棒写了一万五千行，却没有一行简言代码被真正执行过。 这一棒把它接通：源码走完词法、语法、语义、中间表示，交给 C，再交给 gcc。

.jy → 词法 → 语法 → 语义 → IR → C → gcc → 机器码

同一段逻辑，三种样子 排序里的冒泡

简言源码 示例/排序.jy

函数 冒泡(数: 可变借用 整数 组) {
    私有 整数 n = #数
    私有 整数 i = 0
    当 i << n 就 {
        私有 整数 j = 0
        当 j << n - 1 - i 就 {
            如果 数[j] >> 数[j + 1] 就 {
                私有 整数 临时 = 数[j]
                数[j] = 数[j + 1]
                数[j + 1] = 临时
            }
            j = j + 1
        }
        i = i + 1
    }
}

中间表示 基本块 + 三地址码

函数 冒泡(可变借用 数: 整数 组)
L0:
    %t1 = 载 %数
    %t2 = 长度 %t1 : 整数
    存 %n, %t2
    %t4 = 常量 0 : 整数
    存 %i, %t4
    跳 L1
L1:
    %t6 = 载 %i
    %t7 = 载 %n
    %t8 = 小于 %t6, %t7 : 布尔值
    条件跳 %t8 则 L2 否则 L3
L2:
    %t9 = 常量 0 : 整数
    存 %j, %t9
    跳 L4
L3:

左边那份 C 里，vN 是「寄存器候选」， goto L 是「块的边界」。
看着笨，但这正是后面做原生后端时要替换掉的两层——现在它们有明确的名字和位置。
值不复用，块全用 goto。 每条 IR 指令一个 C 变量，一个函数几百个局部变量；块之间不分析控制流，直接跳。 这些看着笨的地方，gcc -O2 的寄存器分配会全部消掉——现在偷的懒，正是原生后端将来要补的活。
